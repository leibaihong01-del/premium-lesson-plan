## 三、学生成果样本机器可读性（结构高 / 语义中低）

样本：王欢、杨振海、汪子涵。

| 维度 | 结果 |
|---|---|
| 文档结构 | 段落 133~173、表格 4、参考文献 6~8，均可解析 |
| 标题结构 | 按数字前缀识别 H1 数量偏高（王欢文本识别 11 个 H1，实际章节 5 个），说明文本规则不可靠，需按样式+上下文判定 |
| 格式污染 | 加粗 run 15~21 处、底纹 run 131~171 处、字体仅 7.5/8/10pt 三类 |
| 禁用表达 | 3 份初稿均含“研究对象”×2 |
| 图片 | 3 份初稿均无图片 |

结论：学生初稿的结构信息可机器抽取，但“标题/正文语义”必须靠样式与规则判定，不能靠短文本猜测。

## 四、任务书机器可读性（表格结构高 / 段落低）

任务书正文段落仅约 48~54 字，内容全部位于 18 行 × 14 列的单张表格中，结构在 3 份样本中一致。

| 能力 | 结果 |
|---|---|
| 基础字段 | 二级学院/班级/姓名/学号/选题名称/选题类型 可抽取（6/8，指导教师可从学生信息.json 补齐） |
| 设计目标 | 可抽取 |
| 设计任务 | 可抽取 |
| 设计进程 | 可抽取（6 个阶段：选题/任务书/实施/评阅/答辩/检查） |
| 预期成果 | 可抽取 |

结论：任务书可作为 Content Quality Engine 的验收依据；字段抽取必须先按表格单元格映射，不能按段落文本。
