# 王欢 v0.2 基准版 vs 邱志豪成果 视觉 DNA 差异审计

时间：2026-08-06
性质：只读审计

## 一、对比对象

- A：王欢_毕业设计成果_模板迁移验证版.docx（v0.2 模板实例基准）
- B：邱志豪_毕业设计成果.docx（v0.2 生产链输出）

## 二、十项对比

| 项目 | A（v0.2 基准） | B（邱志豪成果） | 差异 |
|---|---|---|---|
| Paragraph Style | 正文内容 103 / 参考文献 9 | 正文内容 79 / 参考文献 7 | 内容量不同 |

## 三、为什么两者都声称 v0.2 但视觉效果不同

1. A 是 v0.2 模板实例层基准：只执行 TemplateInstanceBuilder（黄金模板 + 字段替换），不执行 ContentAdapter，因此全部格式由模板样式继承；
2. B 是 v0.2 生产链完整输出：TemplateInstanceBuilder + ContentAdapter + Template Style Precedence 后处理，内容为邱志豪成果初稿，格式由生产流程显式重赋；
3. 内容来源不同（杨振海模板内容 vs 邱志豪初稿），导致段落数、参考文献数、分页不同；
4. 结构 DNA 一致：分节 4、封面、表格数量、TOC、页面尺寸、页边距。

## 四、结论

视觉差异属于“模板实例层”与“完整生产层”的层级差异，不是 v0.2 路径被破坏：

- A 验证模板层；
- B 验证生产层；
- 两者共享结构 DNA；
- B 的显式格式来自 Template Style Precedence 规则，符合 v0.2 生产路径定义。
