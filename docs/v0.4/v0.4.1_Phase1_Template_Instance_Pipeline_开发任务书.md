# v0.4.1 Phase 1 Template Instance Pipeline 开发任务书

状态：开发任务书（设计稿）
日期：2026-08-03

## 1. 目标

在保留模板资产前提下，实现污染清洗后的内容替换，生成第一份合格毕业设计成果 Word。

## 2. 范围

- 只处理毕业设计成果生成链路。
- 保留 v0.3 可回滚；配置开关 word_engine.version: v03 / v04.1。

## 3. 模块布局

```text
00_系统配置/模块/v04/result_pipeline/
  clean/    docx_cleaner（初稿 -> Document IR）
  skeleton/ template_loader、skeleton_manager（模板资产保护）
  ir/       document_ir（中间结构）
  region/   region_mapper、region_filler（区域映射与填充）
  style/    style_applier（模板格式应用）
  diff/     document_diff（结构/资产/内容/格式四类检查）
```

## 4. 数据契约

- Document IR：只含 document_type、metadata、blocks（heading/paragraph/table/reference/page_break/fixed_region），无 font/style/xml。
- template_region_map.json：cover.title -> student.title；body.main -> document.blocks；reference -> document.references。
- Template Profile：页面、样式、标题、表格、参考文献、页码、固定区域。

## 5. 实施步骤

1. 模板骨架保护测试：复制模板，校验 section=4、table=6、TOC 存在、页码域存在，100% 一致。
2. 内容清洗：学生初稿 -> Document IR，断言无 font/color/style。
3. 区域映射：建立 template_region_map.json。
4. 区域填充：学生信息、正文、表格、参考文献按映射填入模板骨架。
5. 样式应用：格式全部来自模板 Profile。
6. Diff 验证：输出 template_diff_report.md。

## 6. 验收标准

- 结构：模板 4 分节、6 表、页码域、目录域全部保留。
- 内容：学生信息正确、正文完整、参考文献完整。
- 格式：无初稿字体/颜色/底纹残留。
- 自动化：Diff 报告可输出；v0.3 回归继续通过。

## 7. 禁止事项

- 禁止 deepcopy 学生内容段落/run/表格；
- 禁止从学生文件读取 run.font/color/style；
- 禁止“模板 -> JSON -> 新 Word”；
- 禁止删除模板固定页、分节、域、固定表格。

## 8. 回滚

失败立即切回 v03；保留 v04.1 代码与测试数据。
