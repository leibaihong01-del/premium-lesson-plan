# ADR-001：禁止迁移用户内容格式，允许保留模板结构资产

- 状态：Frozen（v0.4.1 修正）
- 日期：2026-08-03

## 决策

v0.4.1 文档生成链路：

- 禁止：迁移用户内容中的格式属性（字体、字号、颜色、底纹、高亮、下划线、原 run/paragraph 属性）。
- 允许：保留经过验证的模板结构元素（分节、页眉页脚、页码域、目录域、封面、承诺页、固定表格骨架、样式定义）。

## 原因

- 只禁止 deepcopy 用户内容，不等于丢弃模板结构；
- Word 不是 HTML：模板依赖结构资产、域、分节与隐藏关系；
- 完整重建 Word 会丢失模板资产，破坏文档结构。

## 边界

| 对象 | 处理 |
|---|---|
| 模板资产 | 保留 |
| 用户内容 | 清洗后重建 |
| 格式规则 | 模板唯一控制 |
