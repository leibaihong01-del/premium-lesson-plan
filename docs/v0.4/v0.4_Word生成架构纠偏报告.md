# v0.4 Word生成架构纠偏报告

日期：2026-08-03
状态：架构修正（未编码）

## 1. 为什么“完整重建 Word”失败

回归事实：

- 模板：4 分节、6 表、145 段、16 个页码域、含目录域；
- v0.3 王欢：4 分节、6 表，结构对齐模板（存在格式污染风险）；
- v0.4 王欢：1 分节、4 表，缺封面/承诺页表格，结构被破坏。

结论：v0.4 的问题不是字体，而是“重新创建整个 Word”导致模板资产丢失。

## 2. v0.3 的保留价值

v0.3 本质是模板驱动：保留模板骨架（分节、固定页、表格、域），问题在于“复制内容太粗暴”，格式属性污染。

正确做法不是推翻 v0.3，而是站在 v0.3 肩膀上修正内容迁移方式。

## 3. 模板骨架保留方案

```text
模板docx
  ↓ Template Skeleton Extract
保留：
  - section / 分节
  - header / footer
  - cover / 承诺页
  - 固定表格骨架
  - 页码域 / 目录域
  - 样式定义
```

禁止把模板结构当作“待重建内容”。

## 4. 内容清洗方案

```text
用户内容区域
  ↓ Content Clean
只保留：文本、标题层级、表格数据、参考文献文本
  ↓ Document IR
不携带：font / size / color / style / xml
```

## 5. 新迁移策略

```text
模板docx
  ↓ 保留模板骨架（结构资产不动）
  ↓ 定位动态内容区域
  ↓ Content Clean -> Document IR
  ↓ 在模板骨架内填充结构化内容（新建 run/paragraph，不迁移格式）
  ↓ Style Apply（模板样式）
  ↓ Diff 验证
  ↓ 输出
```

## 6. 生成边界

A. 模板资产（保留）：封面、承诺书、固定表格、分节、页眉页脚、页码域、目录域。
B. 内容资产（重建）：姓名、课题、正文、参考文献。
C. 格式规则（模板控制）：字体、字号、标题。

## 7. 立即调整

1. 暂停 v0.4 Rebuild Layer（new Document 方向）；
2. ADR-001 已修正：禁止迁移用户内容格式，允许保留模板结构元素；
3. 后续开发按“模板驱动重构”路线：模板骨架 + 内容清洗 + 区域填充 + Diff。
