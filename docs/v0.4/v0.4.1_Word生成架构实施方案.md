# v0.4.1 Word生成架构实施方案（设计稿）

版本：CourseAgent v0.4.1
模式：Template Instance Pipeline（设计冻结，未编码）

## 一、架构调整背景

- v0.3 问题：deepcopy 用户内容 + run 原位修改，导致用户内容格式污染模板。
- v0.4 初版问题：Document IR -> 重新创建 Word，导致模板资产丢失（分节、固定页、页码域、TOC 域、封面结构、固定表格）。

## 二、核心原则

模板不是格式参考，而是生成资产。

生成模式：Document Rebuild -> Template Instance Pipeline。

## 三、总体架构

```text
模板文件.docx
  ↓ Template Skeleton Layer
模板骨架实例
  ↓
学生初稿.docx -> Content Clean Layer -> Document IR
  ↓
Region Fill Layer（内容区域精准填充）
  ↓
Style Apply Layer（模板规则应用）
  ↓
WPS 处理阶段
  ↓
Document Diff
  ↓
最终成果
```

## 四、四层设计

### Layer 1：Template Skeleton Layer
- 保留模板 Word 对象本身，禁止“模板 -> JSON -> 新 Word”。
- 保留：section 数量/属性、page size/margin、header/footer、封面、承诺书、声明页、签字页、固定表格（数量/位置/合并/行列/边框）、TOC 域、页码域。

### Layer 2：Content Clean Layer
- 输入学生初稿，输出 Document IR。
- 只提取文本、标题层级、表格数据、图片引用、参考文献；删除字体、颜色、样式、XML。

### Layer 3：Region Fill Layer（新增核心）
- 将 Document IR 填入模板骨架的指定区域。
- 区域类型：固定文本区、数据填充区（学生信息）、正文区（章节/总结）、表格填充区（只填 cell 内容）。
- 产物：template_region_map.json，例如 cover.title -> student.title、body.main -> document.blocks、reference -> document.references。

### Layer 4：Style Apply Layer
- 格式唯一来自 Template Skeleton + Template Profile。
- 禁止从学生文件读取 run.font/run.color/run.style。

## 五、Phase 1 重新定义

Phase 1 = Template Instance Pipeline：在保留模板资产前提下，实现污染清洗后的内容替换。

## 六、实施步骤

1. 模板骨架保护验证：复制模板，校验 section=4、table=6、TOC 存在、页码域存在，100% 一致。
2. 内容清洗验证：学生初稿 -> Document IR，检查无 font/color/style。
3. 区域映射：建立 template_region_map.json。
4. 区域填充：信息替换、正文填充、表格填充。
5. 模板格式恢复：应用 Template Profile 规则。
6. Diff 验证：输出 template_diff_report.md。

## 七、Diff 指标

- 结构保护：模板 section == 输出 section。
- 资产保护：表数量、固定页、域。
- 内容完整：标题、正文、表格。
- 格式污染：字体、字号、颜色、底纹。

## 八、模块调整

```text
result_pipeline/
  clean/    docx_cleaner
  skeleton/ template_loader, skeleton_manager
  ir/       document_ir
  region/   region_mapper, region_filler
  style/    style_applier
  diff/     document_diff
```

## 九、与 v0.3 关系

- 不替换 v0.3：保留模板处理经验；v0.4.1 增加内容清洗、区域填充、Diff 验证。

## 十、验收标准

- 模板：4 分节、6 表、页码域、目录域全部保留。
- 内容：学生信息正确、正文完整、参考文献完整。
- 格式：无字体/颜色/底纹污染。
- 回归：v0.3 继续可用。

## 十一、冻结结论

v0.4.1 采用：模板资产保护 + 内容清洗 + 区域填充 + 模板格式控制 + 差异检测。后续 Codex 任务书围绕 Template Instance Pipeline，而不是 Rebuild Layer。
