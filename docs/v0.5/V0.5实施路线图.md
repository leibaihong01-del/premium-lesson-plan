# V0.5 实施路线图

版本：0.5-draft
状态：待设计评审

## 总体原则

- 新模块默认关闭；
- 可独立测试；
- 不破坏现有稳定流程；
- 不直接修改现有 Skill 规则；
- 每阶段完成设计评审后再编码。

## Phase 1：Template Schema

目标：将模板解析为带空间约束的知识对象。

交付物：

- `template_schema.json` 规范；
- Template Intelligence Layer 独立模块（默认关闭）；
- 任务书模板 Schema 样例；
- 成果模板 Schema 样例。

验证标准：

- 能从模板识别页面约束、区域定义、容量限制；
- 任务书模板解析为 2 页约束；
- 不改变现有生成行为。

## Phase 2：生成规划

目标：生成前输出内容分配、页面布局与风险预测。

交付物：

- `generation_plan.json` 规范；
- Generation Planner Agent（默认关闭）；
- 邱志豪案例规划回测：任务书首轮即应预测超页风险；
- 规划报告样例。

验证标准：

- 规划结果可解释；
- 超页风险预测命中率高于随机；
- 启用规划后任务书页数达标率提升。

## Phase 3：经验优化

目标：从案例中学习，形成经验记录与候选策略。

交付物：

- `experience_record.json` 规范；
- Experience Optimizer（默认关闭）；
- 问题层分类规范；
- 王欢/汪子涵/邱志豪案例经验回填。

验证标准：

- 每个案例可归入问题层；
- 经验以根因+策略记录，不以操作步骤记录；
- 候选策略不进入正式 Skill。

## Phase 4：策略选择

目标：根据历史案例自动选择最优生成路径。

交付物：

- `strategy_scores.json` 规范；
- Strategy Selector（默认关闭）；
- 策略评分与回退机制；
- 三案例策略评分基线。

验证标准：

- 样本量足够时选择高分策略；
- 样本量不足时采用保守策略；
- 质量下降可回退；
- 策略选择过程可解释。

## 阶段退出条件

每阶段完成：

1. 设计文档更新；
2. 独立模块可运行（默认关闭）；
3. 案例验证通过；
4. 无现有流程回归。

## 最终验收

启用 V0.5 后：

- 任务书/成果首轮生成达标率提升；
- 问题能按问题层自动归类；
- 策略选择自动采用更优方案；
- 经验沉淀可追溯、可回退；
- 无 if 规则堆积。
