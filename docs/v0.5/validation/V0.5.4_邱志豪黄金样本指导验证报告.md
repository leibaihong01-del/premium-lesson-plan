# V0.5.4 邱志豪黄金样本指导验证报告

- 方式：离线模拟，不修改代码、不接入生产、不升级 Skill
- 输入：TKM（V0.5.3）、TQM（V0.5.4）、邱志豪任务信息
- 参考样本：王欢任务书（黄金样本）

## 一、如果使用 TQM，预计哪些问题可避免

1. 首轮 3 页超页：通过 `page_constraint=2` + 区域容量预算 + 空段落 slack 预算，可在生成前识别并避免；
2. 生成后“删除空段落”的补救：TQM 要求空段落按 slack 使用，生成阶段即控制；
3. 预期成果/签字区脱离第 2 页：TQM 将签字区标记为页面保护区域；
4. 内容密度偏移：设计目标 238/6、设计任务 197/7、预期成果 224/11 均在黄金区间内；
5. 区域策略不一致：设计任务按“资料收集→撰写→结构原理→检修周期→作业流程→工具材料”组织，符合黄金表达习惯。

## 二、与原生成版本对比

### 页面结构

| 维度 | 原首轮生成 | TQM 目标 |
|---|---|---|
| 页数 | 3 页 | 2 页 |
| 第1页 | 基本信息+设计目标+设计任务前段 | 基本信息+设计目标+设计任务+时间安排前段 |
| 第2页 | 设计任务后段+时间安排 | 时间安排后段+预期成果+签字区 |
| 第3页 | 预期成果尾部+签字区 | 不存在 |

### 内容密度

| 区域 | 原首轮 | TQM 目标 | 黄金样本 |
|---|---|---|---|
| 设计目标 | 240/9 段 | 238/6 段 | 246/6 段 |
| 设计任务 | 200/10 段 | 197/7 段 | 201/7 段 |
| 预期成果 | 224/11 段 | 224/11 段 | 224/11 段 |

### 区域布局

- 原生成：内容区尾部空段落挤占页容量；
- TQM 目标：空段落 slack 预算明确（3/3/0），签字区固定第 2 页；
- TQM 还引入“内容策略”，不只做容量约束。

## 三、TQM 是否真正提供了新增价值

有。

- TKM 只回答“不能超过 199 字符”；
- TQM 回答“接近 201 字符、7 个任务、按执行路径分解、哪些区域紧凑、哪些区域允许展开”；
- TQM 让验收从“模板容量”升级为“优秀成果规律”。

注意：这是离线模拟的设计有效性验证；真实价值仍需在启用 Planner 后做一次端到端回归确认。

## 四、Schema 发现

1. `generation_plan` 需显式增加 `golden_reference_id`，记录参考样本；
2. `quality_memory` 需增加 `applicable_scope` 与方向/文档类型维度，避免 AFC 特征被误用到电梯；
3. 需增加 `blank_paragraph_slack` 到 plan 的内容预算；
4. 需增加 `text_wrap_estimate` 到 TQM 或 plan，避免只按字符数判断；
5. `content_features` 需明确“内容策略”，不能只记录长度与段落数；
6. 多黄金样本时需定义“特征比较边界”，允许同方向/同类型之间比较，跨方向只参考结构策略。

## 五、结论

TQM 设计在离线模拟中有效：

- 能提前指导内容密度与页面布局；
- 能避免原生成版本的首轮超页问题；
- 新增价值来自“优秀规律 + 内容策略”，而非仅模板容量；
- 可进入 Schema 微调，之后再做真实端到端验证。
