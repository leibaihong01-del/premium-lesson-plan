# ADR-005：任务执行前需求预审机制

状态：已采纳（规范层）    日期：2026-08-02

## 背景

任务执行前缺少统一的需求预审协议，存在“需求未复述即执行”“信息缺失默认补齐”“未确认即进入最终生成”等风险。

## 问题

如何在低成本前提下，保证正式生成、设计、修改、执行前，需求理解准确、信息完整、方案合理、关键决策经过人工确认。

## 决策

在 AGENTS.md 增加“任务执行前需求预审协议”，作为行为规范层强制要求，四个阶段：

1. 需求复述；
2. 信息完整性检查；
3. 第一性原理审查；
4. 人工确认。

V1.0 阶段只作为行为规范执行，不实现 Preflight Agent 模块。

## 不采用方案

- 直接实现 Preflight Agent 代码模块：成本高、时机过早，V1.0 先验证规范价值。
- 仅口头提醒、不落文件：无法强制与追溯。
- 完全交给模型自审：缺乏确定性，无法保证人工审批点。

## 当前实施范围

- 仅更新 AGENTS.md 行为规范；
- 新增本 ADR 记录；
- 不修改任何代码、不新增 Python 模块、不调整 Workflow。

## 后续演进计划

- V1.0：行为规范执行，人工执行四阶段预审；
- V1.1：评估是否实现 Preflight Agent 模块，把四阶段部分自动化（信息完整性检查、规则校验）；
- 自动化后仍保留“人工确认”节点。
