# CourseAgent 长期成长原则

版本：1.0
状态：最高约束
适用范围：CourseAgent 后续所有模块设计与版本演进。

## 一、核心原则

CourseAgent 不允许通过一次案例、一条规则、一次失败结果直接改变自身行为。

所有能力提升必须遵循：

```
案例执行
→ 结果分析
→ 问题诊断
→ 经验候选
→ 多案例验证
→ 人工确认
→ 知识固化
→ 后续调用
```

该原则是未来所有模块设计的最高约束。

## 二、经验产生原则

每次任务执行后，系统必须能够提取：

- 做了什么；
- 结果如何；
- 出现什么问题；
- 为什么出现；
- 如何解决；
- 是否具有复用价值。

形成 Experience Candidate。

## 三、经验验证原则

任何经验不得因单案例成功直接成为规则。

必须经过：

- 多案例验证；
- 适用范围分析；
- 风险判断；
- 人工确认。

通过后才能进入长期知识。

## 四、经验使用原则

已确认经验只能作为：

- Planner 参考；
- Reviewer 判断依据；
- Revision 策略建议。

不能覆盖当前模板约束。

## 五、防止错误进化

禁止：

- 自动修改 Skill；
- 自动修改 Prompt；
- 自动修改核心规则；
- 自动扩大经验适用范围。

## 六、长期成长路线

固定为：

- V0.6：单案例自动闭环；
- V0.7：多文档经验积累；
- V0.8：经验辅助生成优化；
- V1.0：职业教育教师数字孪生 Agent。

## 七、约束优先级

1. 本长期成长原则；
2. AGENTS.md 行为规范；
3. 项目知识库与 Skill 规则；
4. 具体任务指令。

冲突时，以本原则与 AGENTS.md 为准。
