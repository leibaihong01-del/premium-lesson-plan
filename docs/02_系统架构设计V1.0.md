# 优秀高职教师智能体核心底座架构设计 V1.0

日期：2026-08-01    依据：《优秀高职教师智能体建设方案》《生命力系统设计方案》

## 一、系统定位

模拟、增强、持续提升一名优秀高职教师的综合能力，形成“教师数字孪生 + 教学资源生产系统 + 教师成长辅助系统”。核心底座为：总控智能体 + 需求转译 + 记忆系统 + 自我进化系统。

## 二、分层架构

```text
输入层：用户自然语言 / 文件 / 反馈
   ↓
需求转译层（Requirement Transfer）：意图理解→目标分析→任务拆解→执行计划
   ↓
总控层（Orchestrator）：任务状态机，调度执行/审核/修复/打包/复盘
   ↓
执行层：现有 CourseAgent Agents 与 Modules（planner/writer/reviewer/learner/router/checkers/packager）
   ↓
质量层：四维评分≥95 + 视觉检查 + 满意度预测（Intention Alignment）
   ↓
记忆层（Memory）：任务/决策/规则/成败/用户偏好/模板/问题方案
   ↓
进化层（Self-Evolution）：问题发现→原因分析→方案→验证→经验→可控升级
   ↓
知识更新层：政策/标准/案例/技术/趋势（预留接口）
```

## 三、核心底座模块

### 1. 总控智能体（Orchestrator）

状态机：TRANSLATED → PLANNED → EXECUTING → REVIEWING → REPAIRING → PACKAGED → LEARNED → DONE。每步记录工作日志，支持中断恢复。

### 2. 需求转译智能体（Translator）

自然语言 → TaskSpec（目标、意图、交付物、约束、质量要求、算力提示、置信度）。规则+关键词零/低Token解析，结合用户偏好记忆，输出可执行计划。

### 3. 记忆系统（Memory）

统一命名空间：tasks、decisions、rules、failures、successes、improvements、user_preferences、templates、problems、solutions、best_practices。提供 put/get/search，并沉淀用户评价标准。

### 4. 自我进化系统（Evolution）

问题发现（自动检测/用户反馈/外部变化）→ 分类 → 原因分析 → 方案 → 验证 → 经验沉淀 → 可控升级（L1规则自动、L2流程验证、L3架构人工确认）→ 成长评分。

### 4.1 问题解决Agent（ProblemSolver）

原因分析 → 候选方案 → 择优 → 验证计划，与 Evolution 联动。

### 4.2 满意度预测（Intent Alignment）

文字要求匹配 + 隐含目标检查 + 优秀教师标准检查，输出对齐分与“可输出/建议优化”结论。

### 4.3 知识更新Agent（KnowledgeUpdateAgent）

来源登记、更新导入、影响分析、规则升级建议（L1自动/L2验证），联网监测为后续接口。

### 4.4 精品课程建设专家（ExcellenceEngine）

五维诊断：教学逻辑、内容体系、职业特色、创新设计、评价体系；输出课程等级（普通/优质/精品/标志性成果）与提升建议。

### 4.5 教师能力模块（capabilities）

竞赛辅助（比赛方案/教学设计/讲稿/答辩预测）、教研辅助（教改课题/论文框架）、成果转化（软著/专利交底），均以结构化生成器提供基础框架。

### 4.6 用户理解模型与自检

user_model：从任务与反馈沉淀用户偏好（精品标准、闭环报告、岗位能力）；tools/agent_selfcheck.py 输出Agent成长报告（能力状态、记忆统计、成长评分、反思建议）。

### 4.7 总控能力调度与升级审核

Orchestrator.run_capability 统一调度竞赛/教研/成果生成器，输出材料、满意度预测并写入记忆；tools/upgrade_review.py 列出 L2/L3 待审核规则并生成《升级审核报告》。

## 四、可控自主升级

- L1 知识/规则升级：自动。
- L2 工作流升级：需记录并验证。
- L3 核心代码/架构升级：需人工确认。

## 五、版本成长体系

V1 教学资源生产 → V2 智能检测优化 → V3 竞赛辅助 → V4 教研辅助 → V5 成果转化 → V6 教师数字孪生。

## 六、与现有系统关系

本架构作为 CourseAgent 与 premium-lesson-plan Skill 的顶层底座；现有执行模块作为可插拔能力继续复用，后续能力模块按路线图挂载。
