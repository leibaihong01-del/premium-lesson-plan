# 架构原则说明（更新版）

版本：1.2
状态：与《CourseAgent长期成长原则》对齐

## 一、分层架构

```
稳定生产层（V0.4/V0.3）
  ↓
闭环验证层（V0.6）
  ↓
经验积累层（V0.7）
  ↓
经验辅助生成（V0.8）
  ↓
教师数字孪生 Agent（V1.0）
```

## 二、核心架构原则

1. 稳定生产优先：V0.4/V0.3 不因实验模块变更；
2. 新能力默认关闭；
3. 经验与行为分离：经验只作为参考，不直接改变行为；
4. 人工确认门禁：长期知识唯一入口；
5. 渐进演化：单案例 → 多案例 → 知识固化 → 后续调用；
6. 防错误进化：禁止自动改 Skill/Prompt/核心规则/经验范围。

## 三、经验层原则

- 产生：每次任务输出 Experience Candidate；
- 验证：多案例 + 适用范围 + 风险 + 人工；
- 使用：Planner 参考、Reviewer 依据、Revision 建议；
- 固化：人工确认后进入长期知识。

## 四、版本约束

- V0.6：只验证闭环；
- V0.7：只积累经验；
- V0.8：才允许经验辅助生成；
- V1.0：形成教师数字孪生 Agent。

未达到上一阶段验收条件，不得进入下一阶段。

## 五、文档智能基础原则（底层约束）

- 所有文档能力必须优先建立结构化解析能力；
- 不依赖模型直接阅读 Word/PDF 凭经验判断；
- Quality Sense、Knowledge Model、Generation、Review、Revision 都基于结构化中间表示；
- 新增文档类型必须复用同一基础能力，不重新造轮子。
