# 现有项目架构分析报告

日期：2026-08-02
分析对象：CourseAgent（v1.0-baseline + 后续增量）

## 一、项目结构

CourseAgent 包含 agents、capabilities、core、config、context、evaluation、input、memory、models、modules、output、planner、prompts、providers、reports、router、skills、state、tests、tools、validators、workflows、workspace、docs。

## 二、已有能力

### 文件解析
- modules/template_parser.py：解析 Word 模板结构；
- modules/document_writer.py：模板复制 + 单元格填充 + 格式规则；
- 支持 docx 与 fills.json 生成。

### 模板管理
- input/templates、config/agent_rules.yaml、config/models.yaml；
- 检测器按模板结构动态适配（已修复 39x6 硬编码问题）。

### 文档生成
- main.py：规划 → 生成 → 检测 → 修复 → 打包 → 复盘；
- run_agent.py：文件输入/输出式自动工作系统；
- 支持 lesson / practice 两类。

### 检查能力
- modules/format_checker.py：表格、合并、尾段；
- modules/content_checker.py：内容完整、90min、教学过程；
- modules/visual_checker.py：PDF 几何检测；
- validators/vision_consistency.py：视觉一致性校验；
- evaluation/：规则指标评测。

### 模型调用
- models/base.py、registry.py、deepseek.py（文本）；
- providers/vision/：MiMo 视觉 Provider（OpenAI Compatible）；
- router/decision.py 与 router/vision_router.py：文本/视觉路由；
- 配置：models.yaml、vision.yaml，密钥仅环境变量。

## 三、可复用性

- 文件解析、模板匹配、文档生成、检查、打包可直接复用；
- MiMo 视觉可作为模板视觉结构识别与版式校验节点；
- memory 与 skills 可支撑 GraduationAgent 的经验沉淀。

## 四、差距

- 缺少毕业设计专用工作流与数据体系（本次通过 GraduationAgent 工作区补齐）；
- 缺少学生信息 Excel 索引驱动（已建立学生信息管理.xlsx）；
- 缺少任务书解析与模板规则库的自动对接（第二阶段开发）。

## 五、结论

现有 CourseAgent 可作为 GraduationAgent 的能力底座，GraduationAgent 采用“新增工作区 + 复用底座”方式建设，不破坏已有功能。
