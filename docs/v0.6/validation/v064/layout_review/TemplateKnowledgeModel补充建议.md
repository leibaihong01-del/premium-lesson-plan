# Template Knowledge Model 补充建议

## 一、当前缺口

现有 TKM 记录 page_constraint、区域容量、语义角色，但未记录“区域应在哪一页、是否允许跨页、哪些区域必须同页”。

## 二、补充字段

```json
{
  "page_layout": {
    "page1": ["基本信息", "设计目标", "设计任务"],
    "page2": ["设计进程", "预期成果", "签字审核区"],
    "same_page_groups": [["设计目标", "设计任务"], ["预期成果", "签字审核区"]],
    "no_split_regions": ["设计进程"],
    "region_start_page": {
      "设计进程": 2,
      "预期成果": 2,
      "签字审核区": 2
    }
  }
}
```

## 三、建议来源

- 黄金样本王欢任务书页面实测；
- 邱志豪当前成品页面偏移差异；
- 人工审阅标准：视觉重心与黄金版一致。

## 四、注意

- 本建议仅用于 Schema 补充；
- 不修改现有代码；
- 不升级经验；
- 需人工确认后进入 V0.7 后续设计。
