# 页面布局规则建议

## 一、建议规则

1. 设计目标与设计任务必须从同一页开始；
2. 预期成果与签字审核区必须同页；
3. 设计进程（时间安排）应按黄金版落在第2页，不跨页；
4. 页面区域不得因内容起点偏移而改变视觉重心；
5. 允许内容差异，但区域所属页面必须保持黄金版布局。

## 二、建议数据结构

```json
{
  "page_layout_invariant": {
    "same_page": [["设计目标", "设计任务"], ["预期成果", "签字审核区"]],
    "must_start_on_page": {"设计进程": 2, "预期成果": 2, "签字审核区": 2},
    "must_not_split": ["设计进程"],
    "page1_contains": ["基本信息", "设计目标", "设计任务"],
    "page2_contains": ["设计进程", "预期成果", "签字审核区"]
  }
}
```

## 三、验收变化

- 自动验收从“总页数正确”升级为“区域所属页面与黄金一致”；
- 发现区域跨页/起点偏移时输出 deviation，由人工判断是否合理。
