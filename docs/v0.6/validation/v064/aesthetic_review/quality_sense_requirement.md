# Document Quality Sense Layer 需求建议

状态：设计建议，未编码

## 一、目标

让系统从“符合模板”升级为“接近优秀人工成果”，用可计算因素表达审美质量。

## 二、组成

### Page Layout Memory

- 区域所属页面；
- 同页关系；
- 禁止拆分区域；
- 页面阅读顺序。

### Visual Balance Memory

- 页面利用率；
- 内容密度；
- 空白比例；
- 页面重心；
- 首尾页平衡。

### Information Structure Memory

- 区域语义角色；
- 区域关联关系；
- 信息单元完整性；
- 阅读路径连续性。

## 三、验收能力

- 能判断设计进程是否跨页；
- 能判断目标/任务是否同页；
- 能判断预期成果/签字是否同页；
- 能输出 deviation 而非只报页数正确；
- 能在 Planner 生成时优先满足布局不变量。

## 四、边界

- 本阶段只做需求建议；
- 不修改代码；
- 不升级经验；
- 需人工评审后进入 V0.7 后续设计。
