# 后续生产链路调整方案

## 目标

在不破坏 V0.4/V0.6 的前提下，让参考文献质量经验进入后续生成流程。

## 方案

采用“经验调用层”，不修改核心生成链路：

```
v04 成果生成
    ↓
Reference Experience Adapter
    ↓
检查：污染/样式继承/悬挂/对齐
    ↓
发现问题 → 按经验策略局部修正
    ↓
输出最终 DOCX/PDF
```

## 调整项

1. 新增 Reference Experience Adapter（默认关闭）；
2. 加载 reference_format_experience_candidate 的 判断方法/策略；
3. 参考文献样式基于真实 Normal，不继承 Heading；
4. 异常字符与段落级缩进在成果后处理阶段修正；
5. 不修改 v04 生成器内部逻辑。

## 风险

- 经验过度干预：仅当检测到参考文献质量问题才触发；
- 样式 ID 漂移：通过样式名而非固定 ID 定位。

## 验收

- 新生成成果参考文献无污染；
- 多行参考文献对齐一致；
- 页数/表格/正文不受影响。
