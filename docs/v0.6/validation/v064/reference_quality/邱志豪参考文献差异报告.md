# 邱志豪参考文献差异报告（以杨振海模板为基准）

## 一、对比

| 特征 | 杨振海模板 | 邱志豪当前 |
|---|---|---|
| 编号方式 | Word 自动编号 | Word 自动编号 |
| 段落样式 | 参考文献 | 参考文献 |
| 样式缩进 | left=0/hanging=1040/200 | hanging=1040/200（缺 left=0 与 rPr） |
| 段落级缩进 | 无 | left=480/hanging=480 |
| 行距 | style 明确 line=440 exact | 依赖 Normal 继承 |
| 字体 | style 明确 TNR+宋体 | 依赖 Normal 继承 |
| PDF首行 x0 | 70.8 | 70.8 |
| 续行对齐 | 首行+24pt | 首行+24pt |
| 参考文献数量 | 9 | 6 |

## 二、差异分类

1. 模板违反 violation：无（未破坏 2 页/表格/自动编号）；
2. 优秀规律偏差 deviation：
   - 段落级 ind left/hanging=480 覆盖模板样式；
   - 样式缺少明确 spacing/rPr，依赖继承；
3. 可接受差异：
   - 参考文献数量 6 vs 9；
   - 文献内容与方向不同。

## 三、结论

- 视觉首行/续行对齐与模板一致；
- 但样式继承层面存在 deviation：段落级缩进覆盖样式，样式定义不完整；
- 建议作为 Reference Layout Integrity 候选，经人工确认后修正样式继承，不直接固化。
