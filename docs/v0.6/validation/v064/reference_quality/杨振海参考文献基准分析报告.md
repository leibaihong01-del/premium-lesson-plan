## 二、基准规则

- 参考文献区域应使用模板“参考文献”样式；
- 编号由模板 numbering 自动生成；
- 悬挂缩进由样式/编号规则统一，不写死段落级缩进；
- 行距、字体、字号继承模板样式。

杨振海模板可作为 Reference Layout Integrity 的可验证基准。
