# 参考文献残留修正方案

## 一、修正范围

- 邱志豪成果参考文献 [2]~[6]；
- 其他成果统一检查同类残留。

## 二、修正规则

在 Content Clean 参考文献清洗阶段：

1. 去除尾部锚文本：`查看`、`全文`、`链接`；
2. 去除 U+00A0 与连续空格；
3. 保留 `[S]`、`[J]`、年份、页码等文献格式；
4. 保留 GB/T 半角标点。

## 三、验证

- DOCX 与 PDF 中 `查看` = 0；
- 参考文献条数与编号不变；
- 其他章节不受影响。

## 四、边界

- 本方案仅记录，不立即执行；
- 不修改生产链路；
- 经确认后进入清洗规则候选。
