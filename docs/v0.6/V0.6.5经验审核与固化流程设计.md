# V0.6.5 经验审核与固化流程设计

版本：0.6.5-draft
状态：设计稿，未开发
原则：人工确认是经验进入长期知识库的唯一入口；不自动升级；不修改已有模块。

## 一、V0.6.4 输出如何转化为经验候选

### 输入

V0.6.4 每个案例自动输出：

- cognitive_model.json
- generation_plan.json
- gap_report.json
- diagnosis_record.json
- revision_plan.json
- final_result.json
- auto_analysis.md

### 转化规则

候选经验由以下字段聚合：

```json
{
  "candidate_id": "exp_qiu_zhihao_taskbook_001",
  "source_case": "qiu_zhihao_problem",
  "problem": "总页数溢出，实际3页/模板2页",
  "problem_layer": "template_space_constraint",
  "root_cause": "生成阶段未控制内容密度和空段预算",
  "strategy": "按空段预算收敛并复核换行估算",
  "evidence": [
    "qiu_zhihao_taskbook_problem_snapshot_input.pdf",
    "qiu_zhihao_taskbook_revised_v2.pdf"
  ],
  "result": {
    "before_pages": 3,
    "after_pages": 2,
    "rounds": 1,
    "protected_ok": true
  },
  "feedback_source": "auto_detection",
  "status": "candidate"
}
```

转化条件：

- 有真实问题、根因、策略、结果与证据；
- 不包含单案例特殊处理；
- 未经验证的候选不进入长期知识库。

## 二、人工审核界面/流程设计

### 审核清单

审核人逐项确认：

1. 问题是否真实存在；
2. 根因是否准确；
3. 策略是否通用；
4. 结果是否可复现；
5. 是否存在隐私或事实问题；
6. 是否可进入正式经验库。

### 审核动作

- 通过：candidate → approved_candidate；
- 拒绝：candidate → rejected，并记录原因；
- 修改：退回补充证据或调整描述；
- 待验证：保持 candidate。

### 界面元素（设计建议）

- 案例摘要；
- 问题/根因/策略卡片；
- before/after 证据预览；
- 通用性评估；
- 通过/拒绝/修改按钮；
- 审核意见输入框。

## 三、经验状态流转

```
candidate
    ↓ 人工审核通过
approved_candidate
    ↓ 独立验证案例通过
validated_experience
    ↓ 人工确认可固化
long_term_knowledge
```

- `candidate`：自动生成，未人工确认；
- `approved_candidate`：人工审核通过，待独立验证；
- `validated_experience`：独立案例验证通过；
- `long_term_knowledge`：人工确认后进入长期知识库；
- `rejected`：人工拒绝，记录原因，不进入学习。

状态更新必须记录：审核人、时间、意见、依据证据。

## 四、固化后的经验如何被 V0.7 调用

V0.7 读取 `validated_experience` / `long_term_knowledge`：

1. Generation Planner：按问题层与策略检索相关经验；
2. Gap Reviewer：优先使用已验证阈值；
3. Revision Planner：按已验证修正策略生成方案；
4. 模板质量记忆：更新 golden/经验索引（仅人工确认后）；
5. 新任务：自动引用，但不得绕过人工确认边界。

调用原则：

- 经验只做参考与约束；
- 不写死为硬规则；
- 每次使用保留证据链；
- 质量下降可回退。

## 五、V0.7 经验成长系统路线设计

### V0.7.1 经验库

- 数据结构：candidate / approved_candidate / validated_experience / long_term_knowledge / rejected；
- 查询：按 文档类型、方向、问题层、策略；
- 权限：人工审核入口。

### V0.7.2 经验验证

- 用独立案例验证 approved_candidate；
- 记录成功率、回退、适用边界；
- 达到阈值后升级为 validated_experience。

### V0.7.3 经验调用

- Planner 检索；
- Reviewer 引用；
- Revision Planner 采用；
- 提供使用记录与回退机制。

### V0.7.4 经验演化

- 新案例持续产生 candidate；
- 过期/失效经验降级；
- 经验版本化，保留历史轨迹；
- 人工确认始终是长期知识库唯一入口。

## 六、边界与原则

- 本阶段不开发、不自动升级、不修改已有模块；
- 自动系统只产生候选与建议；
- 长期知识库唯一入口 = 人工确认；
- V0.6.4 输出作为 V0.7 经验成长系统的事实输入。
