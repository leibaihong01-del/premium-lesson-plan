# CourseAgent V0.6 轻量运行版本实施方案

版本：0.6-draft
状态：实施计划，未编码
基线：V0.5.7 生成质量闭环 Schema
原则：先证明闭环有效，再扩大自动化；不重构 V0.4/V0.3；新增模块默认关闭。

## 一、目标

V0.6 不追求“自动智能”，只验证一次任务能否跑通：

```
案例输入
 ↓
理解模板和优秀案例
 ↓
生成认知模型
 ↓
制定生成计划
 ↓
生成结果
 ↓
发现差距
 ↓
分析原因
 ↓
局部调整
 ↓
形成经验候选
```

## 二、评估基准

案例：邱志豪任务书。

| 指标 | 基线（旧流程） | 目标（V0.6） |
|---|---|---|
| 首次生成页数 | 3 页 | 经 Planner 提示后接近 2 页 |
| 页面收敛次数 | 需人工修复 | <=2 轮自动 |
| 人工修改次数 | 1+ | 尽量 0 |
| 黄金相似度 | 无对比 | 无 violation，deviation 已判断 |
| 经验候选 | 无 | 形成 candidate |

## 三、V0.6.1 认知链路验证

### 实现内容

1. Cognitive Model Builder
2. Generation Plan Builder

### 输入/输出

输入：模板、黄金案例（TKM/TQM）、学生信息与课题。

输出：

- document_cognitive_model.json
- generation_plan.json

### 验证案例

邱志豪任务书：认知模型应识别 2 页约束、设计任务容量、黄金参考王欢，并预测高超页风险。

### 验收指标

- 认知模型包含 template_context / quality_context / task_context；
- Plan 包含内容预算、页面规划、风险预测、调整建议；
- 超页风险预测命中；
- 不生成文档，仅验证规划。

### 风险

- 只做规划可能偏离真实生成；
- 特征口径不一致导致风险误报；
- 缓解：以邱志豪真实回测为准，风险只提示不阻断。

## 四、V0.6.2 质量反馈验证

### 实现内容

1. Gap Report Generator（规则版）
2. Diagnosis Engine（规则化）

### 输入/输出

输入：生成 DOCX、TKM、TQM。

输出：

- gap_report.json
- diagnosis_record.json

### 验证案例

邱志豪第一版 3 页 vs 黄金 2 页：

- 应输出 `gap_type=violation`（页数）；
- 三级诊断：现象→直接原因→根本原因；
- 若内容密度不同但合理，输出 `gap_type=deviation` 并判断合理性。

### 验收指标

- 已知问题检测率 100%（页数、空段、表格结构）；
- 每条 gap 附证据；
- diagnosis 含直接原因与根本原因；
- 不误判合理差异为错误。

### 风险

- 规则覆盖不足；
- 缓解：本期只覆盖 页数/表格/区域容量/内容密度 四类。

## 四、V0.6.3 局部优化验证

### 实现内容

1. Revision Planner
2. Limited Revision Executor

### 输入/输出

输入：gap_report、diagnosis_record、原 DOCX。

输出：

- revision_plan.json
- 修订后 DOCX（version2）

### 允许操作（限制）

- 内容压缩；
- 段落合并；
- 空段调整；
- 区域内容重新分配。

禁止：

- 全文重写；
- 修改学生信息；
- 修改时间安排；
- 修改签字区；
- 修改参考文献；
- 破坏模板结构。

### 验证案例

邱志豪任务书：3 页 → 2 页，仅调整设计目标/设计任务空段与密度。

### 验收指标

- 页数=2；
- 保护区域逐段一致；
- 修订轮数 <=2；
- 模板结构与表格不变；
- 生成 experience_candidate.json。

### 风险

- 局部执行器误改保护区域；
- 缓解：保护区域清单强制校验，修改前后逐段比对。

## 五、端到端验证

- 使用同一邱志豪案例跑通 V0.6.1 → V0.6.2 → V0.6.3；
- 对比旧流程：
  - 首轮 3 页 vs 新流程最终 2 页；
  - 人工修复次数；
  - 是否形成经验候选；
- 通过标准：
  - 闭环无中断；
  - 所有产物可追溯；
  - V0.4/V0.3 无回归。

## 六、实施边界

新增模块默认关闭：

- 配置开关：`word_engine.v06.enabled=false`
- 独立目录：`00_系统配置/模块/v06/`
- 不修改 v03/v04 生成器入口
- 验收只读取现有产物，不覆盖

暂不实现：

- 自动生成完整文档（继续复用 v03/v04）；
- AI 视觉/OCR/截图比较；
- 复杂评分/相似度；
- Strategy Selector；
- A/B 评估；
- 自动更新黄金样本。

## 七、风险总表

| 风险 | 缓解 |
|---|---|
| 规则模块堆积 | 每阶段独立验证，只实现四类检测 |
| 误诊 | 证据链强制 |
| 保护区域被改 | 修改前后逐段比对 |
| 无限迭代 | max_rounds=2 |
| 生产回归 | 默认关闭 |
