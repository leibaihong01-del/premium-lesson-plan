# CourseAgent V1.1 教师工作闭环设计

日期：2026-08-02
基线：v1.0-baseline + V1.1 DeepSeek/MiMo 双模型方案
模式：只读设计，未修改任何代码
定位：面向职业教育教师的智能助手，不是模型平台
评价标准：以教师实际工作结果为准（能否直接交付、能否评审通过）

## 0. 设计原则

1. 保持 v1.0 架构稳定，Rule Workflow 仍是主链路；
2. 不做重构，不增加无关模型；
3. 模型负责“内容语义”，文档生成模块负责“确定性执行”；
4. 每个环节都有 Evaluation gate 与规则回退；
5. 交付物以“教师可直接使用/套模板归档”为验收标准。

## 1. 精品课程建设完整 Workflow

```text
输入：旧课程标准 / 教案 / 教材目录 / 模板 / 建设要求
  ↓
Preflight（需求复述、信息完整性、第一性审查）
  ↓
Translator → TaskSpec
  ↓
Router（课程建设任务路由）
  ↓
课程诊断
  ↓
课程标准生成
  ↓
教学进度计划生成
  ↓
教案生成
  ↓
教学PPT设计支持
  ↓
文档生成模块（模板套用、Word/PPT生成）
  ↓
质量闭环：格式检测 + 内容检测 + 视觉检测(MiMo可选)
  ↓
修复循环（规则修复，模型辅助）
  ↓
打包归档 + 检测报告
  ↓
Memory 经验沉淀
```

环节说明：

| 环节 | 执行方式 |
|---|---|
| 课程诊断 | DeepSeek 读取课程材料，输出课程定位、岗位能力、思政与评价建议 |
| 课程标准生成 | DeepSeek 草稿 + 规则校验（不得臆造编码/学时/边界） |
| 教学进度计划 | DeepSeek 草稿 + 学时/项目结构校验 |
| 教案生成 | DeepSeek 草稿 + 模板套用（document_writer） |
| 教学PPT设计 | DeepSeek 大纲/讲稿/页面结构；MiMo 页面视觉检查 |
| 质量闭环 | format_checker、content_checker、reviewer、repair、packager |

## 2. 毕业设计自动化 Workflow

```text
输入：专业 / 选题 / 任务要求 / 过程记录 / 答辩信息
  ↓
Preflight → Translator → TaskSpec
  ↓
Router（毕业设计任务路由）
  ↓
毕业设计任务书生成
  ↓
指导记录规范化
  ↓
答辩记录表生成
  ↓
成果文档规范化
  ↓
文档生成模块（套模板、格式检测）
  ↓
MiMo（成果图/表/公式/截图视觉检查，可选）
  ↓
评审 + 修改 + 归档
  ↓
Memory 经验沉淀
```

交付物清单（MVP）：

- 毕业设计任务书；
- 指导记录表；
- 答辩记录表；
- 成果文档规范化版本（按学校模板）。

## 3. DeepSeek 负责环节

| 环节 | 职责 |
|---|---|
| 需求理解 | Preflight 复述、补全 TaskSpec |
| 课程分析 | 课程标准/培养方案诊断 |
| 教学设计 | 教学目标、重难点、教学过程、思政融入 |
| 内容生成 | 课程标准、进度计划、教案、PPT 大纲与讲稿 |
| 毕业设计文档 | 任务书、指导记录、答辩记录表初稿 |
| 质量辅助 | 教学设计合理性建议（仅供规则评审参考，不做最终判定） |

DeepSeek 不负责：文件格式操作、模板套用、最终评分、打包归档。

## 4. MiMo 负责环节

| 环节 | 职责 |
|---|---|
| PPT 页面分析 | 版式、文字溢出、图表清晰度、页面一致性 |
| PDF 视觉信息 | 封面、图表、公式、截图质量（补充规则几何检测） |
| 教材图片理解 | 案例图、结构图、实训场景图语义描述 |
| 精品课程案例 | 从案例截图提取教学设计要素 |
| 毕业设计成果 | 图纸/表格/公式/实验截图检查 |

MiMo 不负责：纯文字内容生成（本期不做图文混合生成）。

## 5. 文档生成模块负责环节

| 模块 | 职责 |
|---|---|
| template_parser | 解析 Word/PPT 模板结构 |
| document_writer | 按 TaskSpec 填充模板生成 Word |
| format_checker | 字体、标题层级、表格、页眉页脚、页面尺寸 |
| content_checker | 内容完整性、禁止内容、边界校验 |
| visual_checker | PDF 几何检测（页数、空白、越界） |
| packager | 输出目录归档、版本命名 |
| runtime | 文件哈希、缓存、增量跳过 |

定位：文档生成模块是“确定性执行层”，模型是“内容语义层”，二者不互相替代。

## 6. 图片资源管理未来如何扩展

### 阶段 1（MVP 内）

- MiMo 仅作为视觉分析输入节点：案例图、PPT 截图、PDF 页面、教材图片；
- 分析结果写入检测报告，不建立资源库。

### 阶段 2

- 建立课程图片资源库：按课程/章节/实训场景分类；
- MiMo 自动打标、OCR、相似去重；
- 文档只保存资源引用，不内嵌大图。

### 阶段 3

- 支持备课侧图片素材建议（基于课程语义检索）；
- 版权约束：仅内部教学引用，来源与授权记录入库，不自动商用。

扩展原则：图片资源库与文档生成解耦，任何阶段都不影响 v1.0 主链路。

## 7. 第一阶段最小可用版本（MVP）

### MVP 范围

精品课程建设（3 类交付物）：

- 课程标准；
- 教案；
- 教学进度计划。

毕业设计辅助（3 类交付物）：

- 毕业设计任务书；
- 答辩记录表；
- 指导记录。

### MVP 技术组成

- Preflight + Translator + Router + TaskSpec；
- DeepSeek 文本增强（默认关闭，试点开启）；
- document_writer 模板套用与格式检测；
- Evaluation gate（规则评分 + 教师人工评审）；
- 打包归档 + Memory 沉淀；
- MiMo 仅提供 PPT/PDF 视觉检测接口，默认不进入主线。

### MVP 成功标准

- 同一批真实任务，分别用“规则”和“DeepSeek 增强”生成；
- 由教师按“可直接使用 / 需小改 / 不可用”三档评审；
- 增强模式可用率高于或等于规则基线才扩大接入；
- 任一交付物必须能直接套模板归档。

### MVP 不做

- 题库批量生成；
- 完整 PPT 自动生成；
- 图片资源库；
- 多模型自动切换；
- 无人值守全自动交付。

本设计为只读输出，等待人工确认后进入代码实现。
