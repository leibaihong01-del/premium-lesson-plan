# 模板语义拆分报告（杨振海原始模板）

## 一、原始模板事实

- 文件：04 杨振海毕业设计成绩评定表 / 05 杨振海毕业设计答辩记录表
- 原始 DOCX 均包含两个语义文档单元
- 表格数量：2
  - Table0：16 行 x 13 列，81 个段落 → 成绩评定主表
  - Table1：1 行 x 1 列，27 个段落 → 答辩记录表
- PDF 页面分布：
  - 第 1 页：成绩评定表（评价指标/答辩时间）
  - 第 2 页：答辩记录表（答辩过程/学生姓名）

| 区域 | 归属 | 页面 | 结构 |
|---|---|---|---|
| 长沙轨道交通职业学院 + 毕业设计成绩评定表标题 | 成绩评定表 | 1 | 段落 |

## 三、1x1 结构检查

- Table1 原始 XML 中 `w:tr` 数量 = 1，`tblGrid/gridCol` = 1；
- 单单元格内包含 27 个段落，属于单格长表布局；
- 结论：1x1 是真实结构，不是解析错误。

## 四、结论

- 原始模板由两个语义文档单元组成；
- 成绩评定表与答辩记录表分别独立建模；
- 当前只做文档理解，不生成新 DOCX、不修改原始模板；
- 后续物理拆分需基于本报告的语义归属执行。
