# Result Region Classification Strategy（成果区域分类路由）

版本：0.7-region-route-v1
原则：能复制的不要模型解决；能规则替换的不要模型判断；只有需要创造和推理的才交给模型。

## A类：完全固定区域（Copy，不解析、不生成）
- 承诺书、原创声明、使用授权、诚信承诺、学院统一说明
- 处理：原样复制，保留页面、文字、格式、签名区、空白区、页码逻辑

## B类：字段替换区域（Replace Fields）
- 封面
- 处理：仅替换学生姓名、学号、班级、指导教师、课题名称；其余全部继承

## C类：结构继承 + 内容重构区域（Reconstruct）
- 主体章节（第1章～参考文献）
- 处理：继承王欢/邱志豪章节组织逻辑、标题体系、表格规范、排版规则；内容按戴吉祥课题重新规划生成

## D类：自动生成区域（Auto）
- 目录：保留TOC域，标题生成后更新
- 页码：保留PAGE域，自动更新

## 执行流程
王欢最终验收版
 ↓
区域拆分（A/B/C/D）
 ↓
A原样复制 → B字段替换 → C内容重构 → D自动更新
 ↓
质量检查
