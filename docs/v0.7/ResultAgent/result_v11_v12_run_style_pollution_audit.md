## 五、污染范围判定

污染等级：C 级偏 D

- 正文：部分污染；
- 参考文献：污染；

v1.2 人工质量下降主要原因：

ContentAdapter 迁移正文时保留了 AI 初稿字符级 run 属性（Arial 8/10pt、Segoe UI 7.5pt、微软雅黑 16pt 等），run 级格式优先级高于模板样式，导致标题与参考文献视觉严重退化。

推荐方案：C（模板样式优先级规则），落地执行按方案 A。

- 方案 A：迁移文本时清除所有源 run 格式，完全继承模板；
- 方案 B：仅清除 Heading run 格式（不足，参考文献仍污染）；
- 方案 C：建立模板样式优先级规则：模板样式 > 内容来源样式。

推荐：C 为主规则，A 为执行策略。

## 七、结论

1. v1.2 内容未退化，退化发生在 run 级格式；
2. 输入资料只提供文字语义，模板提供全部视觉属性；
3. 建议沉淀 Template Style Precedence 规则；
4. Result 验收拆分为两层：Template Compliance（模板符合度）+ Graduation Quality（毕业设计质量）。
