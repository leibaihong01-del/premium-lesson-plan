# 黄金模板视觉 DNA 对齐报告

时间：2026-08-05
性质：只读对齐检查，不修改代码，不生成新版本

## 一、对比对象

- 杨振海毕业设计成果黄金模板；
- 王欢成果 TemplateStyleValidation 版。

## 二、对齐结果

| 区域 | 结构 DNA | 视觉 DNA | 说明 |
|---|---|---|---|
| 封面 | 通过 | 通过 | 20 单元格，15pt 宋体/Times，居中一致 |
| 目录 | 通过 | 待人工 | TOC 域保留，但布局变化后页码未更新 |
| 标题 | 通过 | 部分 | 层级 Heading 1/2 正确；验证版为显式黑体 15/16pt，黄金模板继承样式 |
| 正文 | 部分 | 未对齐 | 首行缩进 0 vs 模板样式；行距显式 15pt vs 模板 22pt；页面密度不同 |
| 表格 | 部分 | 部分 | 数量 6；内容表结构随学生内容变化，表头显式加粗 vs 模板继承 |
| 参考文献 | 通过 | 通过 | 统一 12pt Times/宋体，悬挂缩进 420/420 |

## 三、关键差异

### 正文段落

- 验证版正文首行缩进为 0；
- 黄金模板正文样式含首行缩进与模板行距；
- 验证版行距显式设置约 15pt，黄金模板样式行距更大；
- 页面：验证版 22 页，黄金模板约 18 页，页面密度不一致。

### 标题

- 验证版标题为显式 run 属性（黑体 15/16pt 加粗）；
- 黄金模板标题无 run 级覆盖，完全继承 Heading 样式；
- 视觉层次接近，但不是严格继承。

### 表格

- 正文内容表格由学生内容决定，表头 run 属性为显式加粗；
- 黄金模板表头继承表格样式。

### 目录

- TOC 域保留；
- 分页变化后目录页码存在失真风险，需人工确认或重新更新域。

## 四、结论

Template Structural DNA（机器检查）：

- 分节 4；
- 封面结构；
- TOC 域；
- 表格数量。

基本对齐。

Template Visual DNA（人工视觉）：

- 正文首行缩进；
- 行距与页面密度；
- 标题继承方式；
- 目录页码；
- 表格表头格式。

尚未完全对齐。

## 五、建议

Result 验收应拆分：

```text
Template Structural DNA（机器检查）
+ Template Visual DNA（人工视觉）
```

下一版本需要重点对齐正文首行缩进、行距、页面密度与目录页码。
