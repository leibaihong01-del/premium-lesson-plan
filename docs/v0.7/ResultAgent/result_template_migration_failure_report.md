## 四、问题回答

### 1. 为什么封面变化？

`ResultSkillRunner` 调用 `_transplant_cover(doc, Document(成果记录表.docx))`，把学生成果记录表封面的值单元格段落整段复制到黄金封面值单元格中，替换了黄金封面的段落与字符格式。

### 2. 哪一步破坏模板 DNA？

- `_transplant_cover`：封面值格式跟随学生文件，不再继承黄金模板；
- 正文区间替换：AI 初稿段落按原样式插入，非 Heading 段落被强制改为“正文内容/表注”，Heading 层级保留 AI 初稿层级；
- `_normalize_result_fonts`：强制 Heading 1=16pt 黑体、Heading 2=15pt 黑体、正文 12pt 宋体，覆盖黄金模板样式继承；
- 内容插入后分节由 4 变 5。

### 3. 当前生成链是否真的使用黄金模板？

是，但只保留了“文件级复制”和部分框架，后续封面移植、样式强制、AI 段落插入使黄金 DNA 未完整保留。

## 五、修复建议（本次不执行）

1. 封面：只替换值 run 文本，保留黄金封面值单元格的段落与字符格式；禁止整段搬运学生封面段落；
2. 标题层级：AI 初稿标题映射回黄金模板 Heading 1/2/3，禁止保留初稿层级；
3. 标题字体：继承黄金模板样式，不强制覆盖黑体字号；
4. 分节：保持黄金模板分节结构，禁止新增分节；
5. 迁移方式：复用任务书/答辩记录表成功路径（模板复制 → 字段替换 → 骨架驱动），不重建文档。
