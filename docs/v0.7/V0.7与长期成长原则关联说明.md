# V0.7 与长期成长原则关联说明

## 一、定位

V0.7 是《CourseAgent长期成长原则》中“多文档经验积累”阶段的落地版本，已被冻结为经验记忆基础版。

## 二、原则落实

| 长期成长原则 | V0.7 对应 |
|---|---|
| 经验产生 | 案例闭环结果转 Experience Candidate |
| 多案例验证 | 各文档经验域独立积累与验证 |
| 人工确认 | ExperienceGate 是唯一长期知识入口 |
| 经验使用 | 仅 Planner/Reviewer/Revision 参考 |
| 防错误进化 | 禁止自动改 Skill/Prompt/策略/长期知识 |
| 路线约束 | V0.8 需满足启动条件后再设计 |

## 三、V0.7 冻结边界

- 保留：候选、分析、分类、审核、已验证经验调用；
- 禁止：自动进化、自动策略选择、自动升级；
- 等待：案例数量与独立验证条件满足后再启动 V0.8。

## 四、结论

V0.7 不改变 CourseAgent 自身行为，只建设可信经验记忆；这是长期成长原则的阶段性实现。
