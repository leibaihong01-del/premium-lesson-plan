# 与 V0.7 经验系统集成方案

## 一、接入位置

V0.7 原流程：

```
candidate → approved_candidate → validated_experience → long_term_knowledge
```

V0.7 治理版：

```
candidate
  ↓ Experience Governance Agent
evidence_checked
  ↓ 人工审核
validated_experience
  ↓ 长期稳定
stable_knowledge → long_term_knowledge
```

## 二、职责边界

- V0.7 负责经验存储、分类、调用；
- Governance Agent 负责经验进入前的质量监管；
- 人工确认仍是最终固化入口。

## 三、数据流

1. Experience Candidate 提交；
2. Governance Agent 执行 Evidence Verification；
3. 未通过 → invalid，记录原因；
4. 通过 → evidence_checked；
5. Generalization Check 标记单/多案例；
6. Conflict Detection 检查冲突；
7. 人工审核；
8. 验证通过 → validated_experience；
9. 长期稳定 → stable_knowledge。

## 四、与现有候选的集成

- `reference_quality_experience_candidate`：source_verified 待确认；
- `reference_layout_quality_candidate_v2`：source_verified=true，可进入 evidence_checked；
- 旧汪子涵分析：invalid_evidence，不得进入。

## 五、边界

- 本方案只设计，不编码；
- 不修改现有模块；
- 不自动升级经验；
- 新能力默认关闭。
