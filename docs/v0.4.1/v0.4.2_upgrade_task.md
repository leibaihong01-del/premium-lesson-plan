# v0.4.2 升级任务

## 定位（模块 -> 能力 -> 原因）

1. profile.py（模板画像）
   - 新增 heading_spacing 规则（编号后两空格、两字标题加空格）；原因：当前规则未从模板结构化提取。
   - 新增 reference_rules（字体/缩进/行距/编号类型）；原因：参考文献 Level 0。

2. clean.py（Document IR）
   - references 增加 numbering_type（auto/manual）与排序字段；原因：IR 无编号信息，无法生成自动编号。
   - heading 增加 semantic_role（chapter/section/item/正文短标题）；原因：避免短文本=标题。

3. rebuild/region_fill（生成链路）
   - 参考文献使用 Word 自动编号（numbering.xml），不再写 [n] 文本；原因：Level 1 能力缺失。
   - 目录改为 Heading 绑定 + WPS 更新闭环；原因：当前依赖 Word 后置更新。

4. diff.py（Diff 检测）
   - 增加 run 级检查：color/highlight/shd/underline 残留。
   - 增加标题空格检查、参考文献能力等级检查；原因：当前检测未覆盖。

5. reviewer（内容规范）
   - 增加研究式表达分级扫描（理论研究/算法模型/实验验证）；原因：毕业设计规范要求方案/故障分析导向。

## 验收
- 参考文献 Level 1 自动编号；
- 标题两空格 100%；
- run 污染 0；
- Diff 报告包含上述检查项。
