## 四、本轮修复记录

1. Template Semantic Profile 从模板真实样式解析（按样式名解析 heading 1/2/3、Normal、表注、参考文献、toc 1/2/3），不再硬编码样式 ID。
2. 标题生成改为“编号 Run + 标题 Run”分离，并通过 rFonts hint 防止 Word 保存时合并 Run。
3. （一）（二）等序号项默认正文内容样式，宋体小四、22磅、首行缩进2字符、不加粗。
4. 表格单元格引用“表格内容”样式，水平居中、垂直居中、宋体五号、固定行距22磅。
5. 表注使用模板表注样式，宋体五号、居中、固定行距22磅。
6. 参考文献恢复模板 numbering.xml 自动编号（numId=1，lvlText=[%1]），悬挂缩进继承模板；参考文献区域不参与中文标点规范化，GB/T 7714 半角符号原样保留。
7. 正文中文标点规范化：半角引号转全角引号，中文语境下逗号/句号转全角；代码、型号与英文文献不受影响。
8. Diff 升级为“样式名 + 继承链 + docDefaults”语义比较，兼容 Word 更新后样式 ID 重排与冗余格式清理。
