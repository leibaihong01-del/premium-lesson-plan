# 开发路线图 V1.0

日期：2026-08-01    原则：先底座、后模块、不堆功能

## Phase 0：核心底座（当前）

- 总控智能体（状态机+工作日志）
- 需求转译（TaskSpec）
- 记忆系统（统一命名空间+用户偏好）
- 自我进化系统（问题分类+方案+验证+可控升级+成长评分）

验收：四模块可独立运行，与现有执行层完成最小集成（评审现有教案）。

## Phase 1：执行层接入与满意度预测

- Orchestrator 调度 writer/reviewer/packager/learner
- Intent Alignment：结果与需求一致性检查（已实现基础，冒烟通过）
- 用户反馈回路（部分：feedback进入Evolution分类）
- 知识更新Agent接口（已实现基础）

## Phase 2：教学资源生产模块

- 复用 Skill：课程标准、教学计划、教案、实训教案
- 扩展：PPT、题库、实训任务书、评价标准、资源包（按已确认顺序）

## Phase 3：精品课程建设专家

- 普通课程→优秀课程→精品课程诊断与提升
- 课程逻辑、结构、职教特色强化

## Phase 4：教师能力模块

- 教学比赛辅助（方案/教学设计/讲稿/答辩）
- 学生竞赛指导（训练方案/技术路线/评价标准）
- 教学研究辅助（教改课题/论文）
- 成果转化（软著/专利交底）

当前状态：基础生成器已实现（capabilities/），样例已输出至 output/Phase4样例/；学生竞赛训练方案与评价标准细化待做。

## Phase 5：成长与知识更新

- 用户理解模型（偏好/评价标准/工作方式）
- Knowledge Update Agent（政策/标准/案例/技术/趋势）
- Agent Growth Score 上线

当前状态：用户模型基础（user_model）、知识更新接口、成长评分与自检报告已实现；联网监测与长期模型深化待做。

每阶段完成必须：文档更新、测试通过、经验沉淀、版本记录。
