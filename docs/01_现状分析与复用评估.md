# 现状分析与复用评估

日期：2026-08-01    目标：《优秀高职教师智能体》核心底座建设

## 一、现有架构盘点

### CourseAgent 可执行框架

| 层 | 模块 | 说明 |
|---|---|---|
| 总控 | main.py / batch_score.py | 命令行调度，生成→检测→修复→打包→复盘 |
| Agent | planner / writer / reviewer / learner | 规划、生成、审核、学习四Agent |
| Agent | router_agent / light_judge | 自适应算力路由与轻量判断 |
| 模块 | template_parser / document_writer / format_checker / content_checker / packager / runtime / visual_checker / fast_classifier / decision_cache / escalation | 模板解析、生成、检测、打包、缓存、路由 |
| 记忆 | memory/*.json | 成功/失败/规则/改进/任务指纹/算力历史 |
| 配置 | config/agent_rules.yaml | 评分权重、修复循环、算力档位 |

### Skill 与项目知识库

- premium-lesson-plan Skill：教案/课标/计划/封面/实训生成规则、审核脚本、经验库 E-001-E-015。
- 07_项目知识库：系统总纲、运行协议、Skill规则体系、知识库四层、状态看板、question-log、decision-log、运行日志。

## 二、可复用部分

1. 质量评分闭环：模板30+内容25+教学25+格式20，≥95通过，可直接作为通用质检底座。
2. 模板解析/文档生成：39×6教案模板解析与 run 级填充，可扩展到其他文档。
3. 格式/内容检测：可参数化复用。
4. 打包输出：成品/检测/过程/成长目录结构可复用。
5. 运行时缓存：文件哈希+模板哈希+决策缓存，节省 Token。
6. 自适应路由：复杂度分档、渐进升级、历史降档。
7. 经验规则：E-001-E-015 与运行日志可直接纳入记忆系统。

## 三、缺口分析

| 目标能力 | 现状缺口 |
|---|---|
| 总控智能体 | 仅 CLI 流程，无统一状态机与任务生命周期 |
| 需求转译 | 只有 argparse 参数，不能理解自然语言真实意图 |
| 记忆系统 | JSON 分散，无统一命名空间、查询与用户偏好模型 |
| 自我进化 | 仅“建议重复≥2次”计数，无问题分类/方案/验证/升级分级 |
| 满意度预测 | 无意图对齐检查 |
| 知识更新 | 无政策/标准/趋势更新机制 |
| 教学/竞赛/教研/成果 | 未建设 |

## 四、复用策略

保留现有执行层（writer/reviewer/packager/learner/router/checkers），在其上构建核心底座：总控、需求转译、记忆、自我进化；后续能力模块按 V1-V6 路线逐步挂载，避免一次性堆功能。
