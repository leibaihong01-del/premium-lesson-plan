# Evaluation 生产链路说明

版本：1.0

## 输入
- 学生信息：姓名/学号/班级/专业
- 毕业设计信息：课题名称
- 指导教师信息
- 成绩评定表模板：04 杨振海 毕业设计成绩评定表

## 处理流程
1. 加载模板：复制学院原始模板，禁止重建
2. 字段映射：姓名/学号/班级/课题/指导教师
3. 内容替换：run级替换，样式继承
4. 格式保护：16×13、合并43、签字区/评分区保留
5. 输出生成：DOCX + 内部PDF验证

## 唯一生产入口
EvaluationSkillRunner

## 禁止参与生产
- Document Understanding
- Schema 解析
- 视觉模型
