# 学院规范审查门禁（Institution Compliance Gate）

版本：1.0
适用范围：毕业设计成果交付前的学院规范符合性检查。

## 一、定位

学院检查看的是“有没有违反要求”，不是“写得好不好”。
本门禁负责外部规范符合性，与内容/模板/视觉门禁分离。

## 二、两阶段检查

### 第一阶段：生成前规范解析

- 输入：`01_学院要求/规范知识库`（06 实施方案、07 管理办法、08 检查标准）与 `school_rules` 规则层；
- 提取：必须项、禁止项、格式规则、检查清单；
- 产出：学院毕业设计规范 Skill（college_requirement 配置）。

### 第二阶段：交付前一致性检查

- 输入：最终 DOCX/PDF；
- 检查：是否满足学院要求、是否违反硬性规定、是否遗漏材料；
- 产出：《学院规范符合性报告》。

## 三、影响生成格式的规则必须提前参与

目录格式、字体字号、页眉页脚、参考文献格式、表格格式、封面要求、装订要求等，应在生成前解析并参与生成，不能最后才发现。

## 四、配置（草案）

```yaml
college_requirement:
  cover:
    required: true
  font:
    body: 宋体
  toc:
    level: 3
  table:
    caption_format: "表X.X  表名"
  reference:
    format: GB/T
```

## 五、质量门禁体系（最终流程）

1. 内容门禁：课题匹配、逻辑完整；
2. 模板门禁：Word 结构、样式；
3. 视觉门禁：PDF 渲染、表格、页面；
4. 学院规范门禁：文件要求、检查标准；
5. 交付门禁：目录、页码、最终冻结。

执行顺序：内容 → 模板 → 视觉 → 学院规范 → 交付。
