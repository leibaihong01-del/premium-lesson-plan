# Content Compliance（毕业设计内部内容规范检测）

定位：graduation_design Skill 内部能力，不是 CourseAgent 全局内容规则。

## 边界

- 规则库仅服务毕业设计文档；
- 禁止将毕业设计专用规则写入全局经验库；
- 教案、课程标准、项目申报书等其他文档类型不得使用本规则库，需在各自 Skill 内建立合规规则。

## 保留的底层能力（可复用框架）

- 区域识别（固定/动态/特殊区域）
- 规则匹配
- 差异分析
- 教师反馈学习机制

## 目录

- rules.json：毕业设计候选规则（来源：学校学院文件）
- validator.py：区域感知校验框架
- experience/：本 Skill 内的教师反馈经验沉淀目录
