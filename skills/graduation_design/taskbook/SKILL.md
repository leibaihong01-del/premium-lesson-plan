# 毕业设计任务书专家能力包 v1.0

名称：GraduationDesign TaskBook Skill v1.0
类型：固定模板 + 字段填充 + 内容迁移
触发：基于任务书模板生成学生任务书

## 能力清单

1. 模板解析：2 页 / 1 表（18 行 × 14 列）/ 字段行 0-3 / 内容行 4-5 / 固定行 6-17
2. 生成策略：模板母版复制 + 字段填充 + 学生真实内容迁移，禁止重建 Word
3. 格式保持：内容区 12pt 宋体/Times New Roman；软换行拆段；Wingdings 勾选符号
4. 内容逻辑：虚拟地点不得作为真实资料收集、调研、运行数据来源（v1.0 正式规则）
5. 命名继承：[序号 ]学生姓名 毕业设计任务书 选题名称.docx
6. 内部审核：内容 / 结构 / 格式 / 命名 / 内容逻辑 / 内部渲染页数
7. 交付：只输出正式 DOCX；PDF 仅内部渲染验证
8. 经验迭代：AI 生成 → 人工修订 → 差异分析 → 规则提炼 → 版本升级

## 可执行入口

工作区模块：`00_系统配置/模块/v03/run_taskbook_case.py`

参数：GRAD_STUDENT、GRAD_DIRECTION、GRAD_SEQ（默认 01）
