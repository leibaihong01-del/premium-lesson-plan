# 任务书生成规则 v1.0

## 1. 母版机制

- 直接复制任务书模板，禁止新建 Word、禁止重新排版。
- 字段写入模板单元格首段，保留原 run 格式与字号。

## 2. 内容迁移

- 设计目标、设计任务来自学生真实任务书，禁止复制其他学生内容。
- Shift+Enter 软换行必须拆成真实段落后映射到模板段落。
- 模板空白段落属于版式容量，保留，不删除。

## 3. 勾选逻辑

- 选题类型使用 Wingdings 符号：00A8 未选、00FE 已选。
- 禁止使用文本 ☑ 造成重叠。

## 4. 内容纠偏

- 已知复制残留（如“轨道交通车辆轨道交通”）自动清理并记录。
- 虚拟地点/项目不得作为真实资料收集、现场调研、运行数据来源。

## 5. 命名

- [序号 ]学生姓名 毕业设计任务书 选题名称.docx，各部分空格分隔。
- 禁止 test/final/output/V0.3生成版/AI测试 等临时命名。
