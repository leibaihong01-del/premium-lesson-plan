# 任务书执行工作流 v1.0

## 经验复用模式（已有经验）

1. 读取最新经验：taskbook_common_errors.json / virtual_object_rules.json / template_schema.json
2. 模板母版复制
3. 字段填充（学生信息 JSON）
4. 设计目标/设计任务内容迁移（学生真实任务书）
5. 虚拟对象中和 + 残留清理
6. 内部审核（内容/结构/格式/命名/内容逻辑）
7. 内部 PDF 渲染页数验证
8. 自动修正（最多 3 轮）
9. 交付正式 DOCX

## 学习模式（新模板首次）

1. 模板解析并沉淀 schema
2. AI 生成
3. 人工修订
4. 差异分析
5. 通用规则提炼
6. 经验版本升级
7. 下一次生成验证
