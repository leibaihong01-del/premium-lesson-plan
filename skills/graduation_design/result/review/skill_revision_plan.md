# Result Skill 修订方案（基于 AI vs 人工对比）

日期：2026-08-03

## 对比结论

- AI 生成版：初稿标准化路径，丢失模板母版（1 分节、4 表、无目录域、无页码域、无固定页）；
- 人工修订版：模板保真重构路径，结构完整（4 分节、6 表、目录域、页码域、固定页）。

## 修订项

1. 正式生成入口统一为模板保真重构器（result_reference_builder.py）；
2. 初稿标准化（result_generator.py）降级为内容预处理，仅生成内容源；
3. 生成流程固化：模板解析 → 内容理解 → 内容预处理 → 模板保真重构 → 自动目录 → 内部审核 → 交付；
4. 目录域写入后需 Word 更新（交付说明注明）；
5. 样式映射：正文→正文内容、参考文献→参考文献、标题→Heading 1/2；
6. 表格保真：复制模板表格结构后填充学生内容；
7. 内容合规：学校规则 + 教师经验，区域化检测。

- 王欢 AI vs 人工对比作为回归样本保留。
