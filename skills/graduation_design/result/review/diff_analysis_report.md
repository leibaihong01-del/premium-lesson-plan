# 毕业设计成果三版本差异分析报告（第一轮）

日期：2026-08-03
对比对象：原始模板 vs AI生成版 vs 人工修正版

## 结论

AI 生成版采用“学生初稿副本 + 格式标准化”，丢失模板母版；人工修正版采用“模板母版 + 内容替换”，结构、样式、页码与模板一致。

## 差异明细

| 问题 | AI表现 | 人工修正版 | 原因 | 所属模块 |
|---|---|---|---|---|
| 固定页面 | 无封面/承诺页/目录标记，1 个分节 | 保留封面、真实性承诺页、目录，4 个分节 | AI 以初稿为 Word 基版，未迁移模板固定页 | C 格式继承 |
| 页码 | 无 PAGE 域（0） | 保留模板 PAGE 域（16） | 未继承模板页脚页码字段 | C 格式继承 |
| 标题/正文样式 | Normal (Web)、Heading 2/3 混用 | 正文内容、Heading 1/2、参考文献、表注 | 未以模板样式库为基准映射 | C 格式继承 |
| 表格 | 4 张（初稿结构） | 6 张（模板封面/承诺页表 + 正文表） | 初稿表结构不等于模板表结构，生成时直接保留初稿表 | C 格式继承 / D 文档渲染 |
| 自动目录 | 无 TOC 域 | 目录仍为静态文字，无 TOC 域（模板本身也无） | 模板缺口 + 生成未补自动目录 | E 校验缺失 / A 模板解析 |
| 参考文献 | 8 条，编号 [1]-[8] | 8 条，使用参考文献样式，编号由样式呈现 | 参考文献应继承模板样式与规范格式 | C 格式继承 |
| 页眉页脚 | 单节 linked | 分节独立/链接与模板一致 | 未继承分节与页眉页脚 | C 格式继承 |

## 通用结论

成果必须采用“模板保真重构”，禁止以学生初稿为 Word 基版。
