# 毕业设计成果根因分析报告

## 一、根因

AI 第一版生成策略错误：

```text
学生初稿副本
→ 格式标准化
→ 保存
```

该路径导致模板的样式库、分节、页眉页脚、页码域、固定页、表格结构全部丢失。

## 二、正确策略

模板保真重构（Template-preserving Reconstruction）：

```text
模板母版复制
→ 固定页字段替换
→ 正文/参考文献内容替换（保留模板样式）
→ 自动目录补入（Heading + TOC 域）
→ 保留分节、页码、页眉页脚
→ 内部审核
```

## 三、次级原因

1. 模板解析 schema 未记录分节、页码域、页眉页脚、TOC 域要求；
2. 内部审核未检查分节数、PAGE 域、TOC 域、样式继承、表格与模板一致性；
3. 成果生成器把“内容来源”误当成“文档基版”。

## 四、结论

不是修一个文件的问题，而是生成策略必须从“初稿标准化”改为“模板保真重构”。
