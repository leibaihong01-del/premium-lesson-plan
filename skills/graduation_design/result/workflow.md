# 成果执行工作流 v0.1

1. 模板解析（固定页、标题层级、字体、表格，结构级 Schema）
2. 内容理解解析（初稿段落分类、章节类型、标题级别、缺失检查）
3. 内容结构树建立与模板结构匹配
4. 内容重构与格式标准化生成
5. 内部审核（内容/结构/格式/命名/内容逻辑）
6. 固定页缺口列会审项
7. 内部 PDF 渲染验证
8. 内容规范检测（school_rules 依据，区域化，三级判断）
9. 交付正式 DOCX
10. 人工批阅 → 差异分析 → 规则沉淀 → result Skill v1.0
