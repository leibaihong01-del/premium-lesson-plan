# Review Loop（人工反馈闭环）

毕业设计类 Skill 标准机制：AI 生成版作为原始样本，人工修订版作为学习样本。

## 流程

```text
AI生成版
  ↓
人工修改（在复制版上修改，不改 AI 原版）
  ↓
差异提取（位置 / 类型 / 原因）
  ↓
规则判断（通用规则 vs 单案例修改）
  ↓
经验升级（v0.1 -> v1.0）
```

## 差异提取要求

每个差异必须记录：

- 位置：哪个区域/字段/段落
- 修改类型：内容补充、内容删除、专业表达优化、逻辑纠正、格式调整、模板适配
- 修改原因：为什么人工这样改
- 通用性判断：是否适用于其他学生/模板

## 规则升级要求

- 单案例特殊修改不沉淀；
- 模板规律、专业规律、生成规律才进入经验库；
- 新规则经下一次生成验证后转正。

## 示例

AI：解放西路站故障处理实践
人工：某城市轨道交通AFC设备故障案例分析

规则：虚拟案例不能伪装成真实实践，虚拟地点表述应转为系统、设备、行业标准或典型案例来源。
