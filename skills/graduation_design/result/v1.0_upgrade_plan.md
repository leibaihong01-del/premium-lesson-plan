# Result Skill v1.0 升级方案

## 目标

把 result Skill 从 v0.1（候选）升级为 v1.0（冻结基线）。

## 前置条件

1. 获取学生成果人工修正版（真实修订，不是 AI 副本）；
2. 完成 AI vs 人工差异分析；
3. 候选纠错规则转正；
4. 内容映射规则通过验证；
5. 建立回归案例（脱敏）。

## 升级步骤

1. 人工批阅：用户修改 `人工版本/..._人工修订版.docx`；
2. 差异提取：AI生成版 vs 人工修订版，记录位置/类型/原因；
3. 规则判断：通用规则进入正式经验库，单案例修改不沉淀；
4. 内容理解接入：生成器调用内容理解模块（章节类型、标题层级、缺失检查）；
5. 双版本机制确认：AI样本 + 人工样本 + 元数据；
6. 内部审核回归：模板结构、正文格式、命名、内容逻辑、固定页会审；
7. 冻结：version.json 升 v1.0，登记 registry，提交 Git，打标签 result-v1.0。

## 产出

- result_template_schema（结构级）
- content_mapping_rules
- teacher_correction_rules（转正版）
- naming_rules（含版本区分）
- 回归案例 validation_summary v1.0
