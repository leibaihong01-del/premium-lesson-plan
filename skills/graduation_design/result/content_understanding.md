# Document Content Understanding（成果内容理解模块）

毕业设计成果属于内容重构型文档，生成前必须先理解初稿内容。

## 职责

不是看文字，而是判断：

- 这一段属于什么（章节类型：封面/摘要/正文/总结/参考文献/附录）；
- 应该放在哪里（匹配模板结构）；
- 属于哪个标题级别（一级/二级/三级）；
- 内容性质（研究背景/方案设计/故障分析/总结）；
- 是否缺失（模板要求章节是否存在）。

## 流程

1. 解析初稿段落与表格，建立内容结构树；
2. 识别章节类型与标题层级；
3. 与成果模板结构（fixed / auto_generate / dynamic / special）匹配；
4. 内容重构：按模板顺序组织，禁止正文进入目录、参考文献进入正文、总结缺失；
5. 生成前结构检查，输出缺失清单。

## 与模板填充的区别

任务书：字段级 Schema，定位单元格替换。
成果：结构级 Schema，理解内容后再重构整篇文档。
