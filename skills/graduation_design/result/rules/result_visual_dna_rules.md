# Result Visual DNA Rules

## 1. 规则目的

毕业设计成果质量不能仅通过结构检查判断。

机器结构一致 ≠ 人工视觉一致。

Result 成果必须同时满足：

- Structural DNA；
- Visual DNA；

才能达到黄金模板质量标准。

---

## 2. Template DNA 分层模型

黄金模板 DNA 包含：

### Structural DNA

负责文档结构稳定：

- 封面结构；
- 单元格布局；
- 分节数量；
- 页眉页脚；
- TOC 目录；
- Heading 层级；
- 表格数量与结构；
- 参考文献区域。

### Visual DNA

负责人工视觉一致：

- 页面信息密度；
- 标题视觉层级；
- 正文排版节奏；
- 段落间距；
- 首行缩进；
- 行距；
- 表格视觉效果；
- 参考文献排版效果。

---

## 3. Visual DNA 核心原则

黄金模板提供视觉规范，内容来源只提供语义内容。

禁止根据 AI 初稿、学生初稿自动决定：

- 字体；
- 字号；
- 行距；
- 段落格式；
- 页面布局。

---

## 4. Visual DNA 验收指标

### 页面密度

- 总页数；
- 每页内容量；
- 空白比例。

不得出现明显内容过稀、内容过密、非模板分页。

### 正文格式

- 首行缩进；
- 行距；
- 段前段后；
- 字体字号。

必须继承黄金模板。

### 标题格式

- Heading 层级；
- 字号；
- 加粗；
- 间距。

标题样式优先于来源格式。

### 表格格式

- 表头样式；
- 单元格字体；
- 行高；
- 对齐方式。

保持模板视觉效果。

### 参考文献

- 字体；
- 字号；
- 段落格式；
- 悬挂缩进 0.74cm。

---

## 5. 验收模型

Result 验收必须分两层：

第一层：Template Structural Compliance

第二层：Template Visual Compliance

规则：Structural Compliance 通过不能代表 Visual Compliance 通过。

---

## 6. 产生背景

来源：Result v1.2 模板迁移验证。

发现：结构 DNA 保持后仍出现：

- 页面密度变化；
- 正文格式变化；
- 行距变化；
- 标题视觉下降。

因此建立本规则。

---

## 7. 适用范围

适用于：

```text
skills/graduation_design/result
```

不影响：

- TaskBook Skill；
- Defense Skill；
- Evaluation Skill。

---

## 8. Visual DNA 基准来源

Visual DNA 不以理论规范作为唯一判断依据。

优先级：

```text
黄金优秀成果模板
>
历史人工验收通过版本
>
通用排版规范
```

当前 Result Visual DNA 基准：

- 杨振海毕业设计成果优秀模板；
- 后续人工验收通过的 Result Production 版本。

任何新版本生成后必须与 Visual DNA 基准进行对比。

原因：符合 Word 格式规范 ≠ 像优秀毕业设计，必须存在真实优秀样本作为基准。

---

## 9. Visual DNA Evolution Rule

Visual DNA 不是一次性规则。

每次人工验收发现：

- 页面效果优化；
- 模板调整；
- 排版经验；

必须：

1. 记录问题；
2. 更新 Visual DNA；
3. 保留历史版本；
4. 新版本继承旧版本经验。

禁止直接修改历史基准。
