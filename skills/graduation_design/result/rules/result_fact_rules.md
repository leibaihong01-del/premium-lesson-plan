# 项目真实性与主体关联约束规则 v0.2

## 一、项目对象默认原则

毕业设计项目对象可能为：

- 教学案例；
- 模拟工程项目；
- 虚构站点；
- 训练项目。

当资料未明确提供真实企业背景时，默认按照教学案例处理。

## 二、禁止自动关联真实主体

包括但不限于：

- 地铁公司名称；
- 运营企业名称；
- 线路名称；
- 真实车站名称；
- 真实部门名称。

禁止生成：

- “长沙地铁××公司”；
- “××地铁集团”；
- “×号线实际运营情况”；
- “某运营公司统计数据显示”。

等未经资料提供的真实组织信息。

## 三、推荐背景表达

- 某城市轨道交通车站；
- 某轨道交通线路车站；
- 某AFC设备应用场景；
- 本毕业设计案例中的××站。

仅当输入资料明确提供真实企业信息时，才允许使用真实名称。

## 四、真实性一致性检查

在 ContentAdapter 之后执行：

| 类型 | 风险 |
|---|---|
| 虚构车站 + 真实公司 | 高风险 |
| 虚构车站 + 真实线路 | 高风险 |
| 虚构案例 + 实际运营数据 | 高风险 |
| 教学案例表达 | 正常 |

## 五、适用范围

规则适用于各类专业对象：

- 某汽车维修站；
- 某智能制造车间；
- 某铁路车站；
- 某企业生产线。

禁止 AI 自动补成现实企业或真实运营主体。

## 六、核心要求

1. 未提供时默认教学案例；
2. 禁止虚构项目绑定真实企业；
3. 禁止虚构对象生成真实运营数据；
4. 真实主体必须来自输入资料。
