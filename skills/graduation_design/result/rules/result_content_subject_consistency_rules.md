# Result 内容迁移主体一致性检查规则

## 一、背景

部分成果初稿来源包含真实企业、真实运营单位名称。

毕业设计项目对象可能为虚构或教学模拟案例。

## 二、检查要求

内容迁移前对来源内容执行主体一致性检查。

如果课题为虚构 / 教学模拟案例：

- 不保留真实企业名称；
- 不保留真实运营单位名称；
- 不保留真实线路 / 项目名称。

## 三、保留内容

- 技术方案；
- 故障分析；
- 设计过程；
- 模拟工程描述。

## 四、限制

本规则仅作为内容迁移前检查规则。

不修改：

- 黄金模板；
- TemplateInstanceBuilder；
- v0.2 视觉基准。

## 五、虚构线路名清洗示例

课题地铁站均为虚构/教学模拟案例，正文禁止出现真实城市地铁网络名称、真实线路名称与真实运营单位名称。

禁止：

- 真实城市名 + 地铁 / 轨道交通 / 号线（如：长沙地铁、长沙市地铁、长沙地铁1号线、北京地铁）；
- 真实线路名（如：长沙地铁1号线、某实际城市线路号）。

替换为：

- 某轨道交通线路；
- 某城市轨道交通线路；
- 某地铁某线路；
- 某号线。

保留：

- 课题站名（如“解放西路站”）；
- 学校名称（如封面“长沙轨道交通职业学院”）。

正文段落与内容表格单元格均需执行清洗，封面等模板固定区域除外。
