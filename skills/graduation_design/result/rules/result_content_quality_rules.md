# Result 内容迁移质量规则

## 一、章节逻辑保持

ContentAdapter 执行时必须保持模板章节逻辑：

| 章节 | 匹配内容 |
|---|---|
| 第一章 | 背景与项目对象匹配 |
| 第二章 | 设备/系统介绍匹配 |
| 第三章 | 问题分析与方案设计匹配 |
| 第四章 | 实施过程匹配 |
| 第五章 | 总结匹配 |

## 二、禁止 AI 泛化表达

禁止无具体对象描述：

- 提高系统性能；
- 优化运行效率；
- 具有重要意义。

## 三、要求

内容必须落到具体项目对象、设备、故障与方案，禁止空泛表述。

## 四、专科毕业设计表达规范

毕业设计成果属于专科职业教育成果，不是科研论文，禁止学术论文式表达。

禁止出现：

- 本文
- 本研究
- 本课题
- 本论文
- 实验结果表明
- 研究对象
- 笔者
- 该研究
- 课题研究

允许使用：

- 本设计
- 本项目
- 本方案

表述应以方案、故障排查、设备检修、教学案例为主体，使用职业岗位化语言。
## 五、中文标点字体规则

正文中文标点（含中文引号“ ”‘ ’）必须使用宋体，禁止渲染为 Times New Roman。

技术要点：

- 中文内容所在 Run，ascii/hAnsi 与 eastAsia 都要设为宋体；
- 中文 Run 必须设置 w:hint="eastAsia"，否则 Word/WPS 会把中文引号按拉丁字符用 ascii 字体渲染；
- 仅验证 rPr 属性不足，必须用渲染后 PDF 提取字符实际字体复核。

正文标点全角化，参考文献保持半角格式。
