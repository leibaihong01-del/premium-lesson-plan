# 成果内容映射规则（Content Mapping Rules）

版本：0.1（候选，待人工批阅后转正）

## 一、初稿样式 → 标题层级

- 初稿 Heading 1（标题行）→ 成果标题；
- 初稿 Heading 2（如 `1 引言`）→ 一级标题（Heading 1）；
- 初稿 Heading 3（如 `1.1 设计背景`）→ 二级标题（Heading 2）；
- 初稿 Normal 列表（如 `1. 不读卡...`）→ 正文，禁止提升为标题；
- `（一）...` → 条目（正文内容样式，加粗）。

## 二、章节类型映射

| 初稿章节 | 映射位置 |
|---|---|
| 1 引言 / 绪论 | 正文-绪论 |
| 2 系统/设备概述 | 正文-概述 |
| 3 常见故障分析 | 正文-故障分析 |
| 4 方案设计 | 正文-方案设计 |
| 5 总结 | 正文-总结 |
| 参考文献 | 参考文献（special） |

## 三、固定页

封面、真实性承诺及指导教师声明、目录、摘要：

- 初稿缺失时列会审项，不虚构；
- 目录在正文结构确定后 auto_generate。

## 四、内容原则

- 内容全部来自学生初稿，禁止新增事实；
- 表格与图片随对应章节保留；
- 禁止正文进入目录、参考文献进入正文、总结缺失。
