# TFI 模板继承指数规则

## 定义

TFI（Template Fidelity Index）衡量生成文件对黄金模板的继承程度，不是“有没有内容”，而是“是否忠实继承模板”。

## 权重

| 指标 | 权重 |
| --- | --- |
| 结构一致性 | 30% |
| 表格一致性 | 25% |
| 版面坐标一致性 | 25% |
| 视觉渲染一致性 | 20% |

## 判定

- TFI >= 90：通过，可进入人工审核；
- TFI < 90：禁止交付，生成模块必须先修正。

## 四层检测

1. 结构层：节数、页数（异常增减）、标题树重合率；
2. 表格层：行列、合并、列宽、边框；
3. 坐标层：PDF 第一页文字块 Δx/Δy、最大偏移；
4. 渲染层：PDF 页面转图后的像素差异。

## Reviewer 流水线

```text
Writer
 ↓
Format Reviewer（结构/表格/坐标/渲染）
 ↓
Content Reviewer（专业内容/模板污染/占位符）
 ↓
Final Reviewer（TFI + 综合判定）
```

## 经验

- 对象数量一致不等于模板忠实；必须做坐标与渲染层对比。
- 表格内长内容会导致分页变化，需在坐标层定位偏移来源，禁止用“页数不同正常”掩盖问题。
