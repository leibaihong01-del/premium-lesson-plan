## 一、范围

本版本固化“毕业设计任务书”生成能力，覆盖：

1. 模板解析：2 页 / 1 表（18 行 × 14 列）/ 字段行 0-3 / 内容行 4-5 / 固定行 6-17
2. 生成策略：模板母版复制 + 字段填充 + 学生真实内容迁移
3. 格式保持：内容区 12pt，软换行拆段，Wingdings 勾选符号
4. 内容逻辑：虚拟地点不得作为真实资料收集、现场调研、运行数据来源
5. 命名继承：[序号 ]学生姓名 毕业设计任务书 选题名称.docx
6. 内部审核：内容 / 结构 / 格式 / 命名 / 内容逻辑 / 渲染页数
7. 交付规范：只交付正式 DOCX，PDF 仅内部验证
