# TaskBook 生产链路说明

版本：1.1

## 输入
- 学生信息：姓名/学号/班级/专业/指导教师
- 课题信息：选题名称、选题类型
- 黄金任务书模板：01 杨振海 毕业设计任务书

## 处理流程
1. 模板加载：复制黄金模板，禁止重建 Word
2. 字段映射：姓名/学号/班级/指导教师/选题名称/选题类型
3. 内容生成：设计目标/设计任务/预期成果
4. 内容迁移：从学生任务书初稿迁移真实内容
5. 格式保护：字体/字号/表格结构/合并单元格/勾选符号
6. 内部审核：内容、结构、格式、命名、页数
7. 输出生成：正式 DOCX，PDF 仅内部验证

taskbook_generator（v03/run_taskbook_case.py）
