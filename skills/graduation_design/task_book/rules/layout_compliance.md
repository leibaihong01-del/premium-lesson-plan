# TaskBook Layout Compliance

## 一、页面约束

1. 总页数：2 页；
2. 第 1 页：设计目标、设计任务；
3. 第 2 页：设计进程、预期成果。

## 二、禁止

- 自动分页导致模块拆散；
- 表格跨页异常；
- 内容溢出改变模板布局。

## 三、检查方式

生成后按页面检查关键模块是否落在正确页面。
