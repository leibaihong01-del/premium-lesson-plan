# 最小变更原则（Minimal Change Patch）

版本：1.0
适用范围：所有 Word 文档格式修复、样式修正、XML 级修补任务。

## 一、核心原则

用户指定问题范围 = 修改范围。

禁止以“顺手优化”“一并修复”为由扩大变更边界。

## 二、禁止行为

- 修复 A 问题时顺带优化 B/C/D；
- 修改模板编号体系；
- 将修改扩大影响其他章节；
- 为修复单点问题重新生成全文。

## 三、必须行为

1. 定位具体 XML 节点或段落；
2. 只修改单一属性或文本；
3. 输出修改前后差异；
4. 在最小范围内验证修复结果。

## 四、执行示例

- 参考文献悬挂缩进问题：只修改参考文献区域段落的 ind/tabs/spacing，不重跑全文，不改其他章节。
- 引用格式修复：只处理参考文献章节，不调整正文、标题、表格或全局样式。

## 五、验收

- 修改范围与用户指定范围一致；
- 修改前后差异可追溯；
- 小范围验证通过后才允许进入下一任务。
