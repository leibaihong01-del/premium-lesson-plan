# 内容逻辑审查规则（Content Logic Review）

版本：1.0
适用范围：文档生成后的内部质量审核。

## 一、虚拟对象识别

项目名称、地点名称、企业名称、设备编号等属于虚拟设计案例时：

禁止生成：
- 收集该虚拟对象真实资料；
- 调研该虚拟单位实际情况；
- 获取该地点真实数据。

转换为：
- 收集相关行业资料；
- 分析同类设备原理；
- 参考行业标准；
- 基于典型案例开展设计。

## 二、事实可执行性检查

任务描述必须符合现实逻辑。

错误示例（虚拟对象）：
- 收集XX车站AFC系统运行数据

正确示例：
- 收集城市轨道交通AFC系统运行特点及设备资料

## 三、专业合理性检查

- 技术对象是否正确；
- 工作流程是否符合行业规范；
- 任务要求是否可实现；
- 是否存在 AI 生成的空泛描述。

## 四、执行方式

内容逻辑检查属于内部审核，发现问题自动修正并重新检测；无法判断时列入人工确认点。

典型自动修正模式：

1. `收集 + 站点/企业/地点 + 资料/数据` → `收集相关行业/设备资料`
2. `调研 + 虚拟单位实际情况` → `参考行业标准与同类案例`
3. 空泛描述 → 标记人工确认，不自动改写事实。
