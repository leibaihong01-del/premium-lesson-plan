# 数据真实性原则（Data Truthfulness）

版本：1.0

## 核心原则

有就是有，没有就是没有。

- 禁止根据文件名称推断来源；
- 禁止根据流程推测未存在文件；
- 禁止将 AI 生成文件称为人工修改文件；
- 禁止将模拟数据作为教师反馈数据；
- 禁止将推断结果写入经验库。

## 来源分级

| 类型 | 定义 | 用途 |
|---|---|---|
| A | 真实教师反馈样本 | 可进入教师反馈学习 |
| B | AI生成/AI重构/双版本复制测试 | 仅流程/格式/程序测试 |
| C | 未知来源 | 隔离，等待人工确认 |

## 记录字段

source_type: human_confirmed / ai_generated / unknown

## 学习触发条件

AI版本 != 人工版本 且 source_type = human_confirmed，才允许差异分析与候选规则；否则只做普通质量检测。
