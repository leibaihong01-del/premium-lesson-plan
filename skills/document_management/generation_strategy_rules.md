# 文档生成策略规则

版本：1.0
适用范围：所有模板类文档生成。

## 一、核心原则

不同文档类型必须采用不同生成策略：

- 固定字段型文档：模板填充（template_fill）
- 内容复杂型文档：模板约束下的内容重构（template_reconstruction）

## 二、模板填充型

适用：任务书、成绩评定表、答辩记录表。

流程：模板 → 字段替换 → 少量内容生成 → 生成。

特点：结构固定，变化只有字段与少量内容。

## 三、模板重构型

适用：毕业设计成果、课程标准、教案、项目申报书。

流程：模板结构理解 + 原始材料内容理解 → 建立内容结构树 → 匹配模板结构 → 内容重构 → 模板渲染 → 质量检测 → 输出。

特点：内容驱动，必须先理解“这段属于什么、应该放哪里、是否缺失”，再组织成最终文档。

## 四、禁止

- 禁止把模板填充逻辑直接复制到内容复杂型文档；
- 禁止简单“提取文字 → 填入模板”的搬运式生成；
- 禁止所有文档类型共用同一条生成链路。
