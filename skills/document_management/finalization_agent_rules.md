# Finalization Agent（成果封装阶段）规则

版本：1.0
适用范围：所有文档内容生成完成后的出版处理流程。

## 一、定位

Finalization Agent 属于文档生成完成后的“出版处理流程”，不属于单个格式 Skill。

## 二、执行步骤

1. 检查文档是否存在目录域（TOC field）；
2. 调用 Office/WPS 自动更新整个目录；
3. 保存更新后的文档；
4. 重新打开验证目录页码与标题一致。

## 三、禁止行为

- 手工生成目录文字；
- 仅复制模板旧目录；
- 让用户手动点击更新目录。

## 四、验收

- TOC 域存在且为域代码；
- 目录页码右对齐、点引导符正常；
- 一级/二级/三级标题与参考文献全部进入目录；
- 重新打开后目录无需人工更新。
