# 检测覆盖全量与修复闭环规则

版本：1.0
适用范围：所有文档检查、字符规范、格式修复任务。

## 一、核心原则

检测必须覆盖全量，修复必须有闭环。

禁止：

- 检查一个区域 → 修改一个区域 → 宣布完成；
- 只检查局部即视为全量通过；
- 修复后不重新全量扫描。

## 二、标准流程

1. 全局扫描（正文、摘要、目录、表格、附录、参考文献区域分别登记）；
2. 形成问题列表（位置、字符、上下文、类型）；
3. 分类处理（普通正文 / 序号 / 专业格式 / 参考文献）；
4. 执行修复；
5. 全局复检；
6. 全部通过后才允许输出“完成”。

## 三、验收

- 复检必须覆盖与首次扫描相同的全量范围；
- 待处理问题数 = 0；
- 允许例外必须显式登记类型与数量；
- 参考文献区域按规则独立处理。
