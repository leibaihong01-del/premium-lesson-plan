# 文档字符规范检查规则（DocumentTextNormalizer）

版本：1.0
适用范围：Word 文档正文、摘要、目录、表格、说明文字与参考文献的字符级规范。

## 一、分层判断

字符规范检查必须按区域分层，禁止全文统一替换：

| 区域 | 规则 |
|---|---|
| 普通正文/摘要/目录/表格/说明文字 | 中文语境使用全角标点 |
| 标题编号 | 数字与半角点保留（如 2.1），禁止 2．1 |
| 序号列表 | 序号与内容之间禁止多余空格（如 1.不读卡，禁止 1. 不读卡） |
| 专业符号/代码/标准编号/时间格式 | 保留原格式（如 7:00-9:00、AFC-01、GB/T31478-2015） |
| 参考文献 | 按 GB/T 7714 保留半角符号，禁止全角转换 |

## 二、标点规范

普通中文语境：

- 双引号 “ ”
- 单引号 ‘ ’
- 逗号 ，
- 句号 。
- 冒号 ：
- 分号 ；
- 括号 （）

例外保留：

- 数字与小数/版本点：2.1、1.5
- 时间格式冒号：7:00
- 英文代码/型号：AFC-01
- 标准编号：GB/T31478-2015

## 三、空格规范

- 序号 + 分隔符 + 内容之间禁止多余空格；
- 中文之间禁止异常空格；
- 连续空格按模板要求收敛。

## 四、区域隔离

- 参考文献区域整体跳过全角转换；
- 外部引用内容按原规范保留；
- 修改后必须重新扫描验证。

## 五、验收

- 正文残留半角标点（排除允许例外）= 0；
- 序号后异常空格 = 0；
- 参考文献文字与标点 = 未修改；
- 输出修改区域、修改字符数、跳过区域、验证结果。
