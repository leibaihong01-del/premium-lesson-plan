# 经验自主迭代与提纯机制（Experience Iteration）

版本：1.0

## 一、核心流程

AI生成结果 → 人工修订结果 → 差异分析 → 通用问题识别 → 经验规则提炼 → 经验版本升级 → 下一次生成验证。

## 二、经验提纯

禁止把单次人工修改直接写入正式经验库。

判断标准：

- 仅针对单个学生特殊情况 → 不沉淀；
- 属于模板规律、专业规律、生成规律 → 提炼为正式规则。

## 三、质量筛选

正式经验需满足：

1. 重复出现或具有明确通用价值；
2. 符合模板要求；
3. 符合专业逻辑；
4. 能提升后续生成质量；
5. 具有跨案例通用性。

不满足 → 临时观察区，不影响正式生成。

## 四、版本迭代

- 经验库按版本管理，最新有效版本作为生成默认依据；
- 旧版本保留历史记录，仅用于追踪演化；
- 新规则先经历史案例或下一次生成验证，质量下降则降低权重或回退。

## 五、虚拟对象规则（正式经验示例）

虚拟地点、虚拟项目名称不得作为真实资料收集、现场调研、运行数据来源。

生成内容应转换为：

- 相关系统资料；
- 设备资料；
- 行业标准；
- 技术规范；
- 典型案例资料。
