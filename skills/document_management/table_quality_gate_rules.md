# Table Quality Gate（表格质量门禁）

版本：1.0
适用范围：所有 Word 表格生成与验收。

## 一、表头视觉优先原则

- 表格首行属于视觉重点区域；
- 3~5 个汉字表头：必须优先保持单行；
- 5~6 个汉字表头：尽量保持单行；
- 禁止短标题无意义拆分换行。

## 二、出现换行时的调整顺序

1. 列宽（gridCol 与 tcW 同步）；
2. 表格整体宽度；
3. 单元格空间分配。

禁止为保持当前列宽牺牲表头可读性。

## 三、验收

- 表头字符排列自然；
- 无不必要断行；
- 各列视觉均衡；
- 页面不溢出；
- 表格内容、数据、结构不变。
