# Output Naming Schema（输出命名规范）

版本：1.1

## 一、核心原则

- 所有生成文件名称必须继承模板命名规则，禁止模型自由生成文件名称；
- 命名属于文档生成流程的一部分，不属于后处理；
- 最终交付目录中的文件必须符合学校实际提交命名规范。

## 二、版本区分

| 阶段 | 文件 | 示例 |
|---|---|---|
| AI 原始样本 | AI版本/ | 01 学生姓名 文档类型_AI生成版.docx |
| 人工修订样本 | 人工版本/ | 01 学生姓名 文档类型_人工修订版.docx |
| 最终交付 | 交付目录 | 01 学生姓名 文档类型 选题名称.docx |

AI测试文件、人工修订文件、最终交付文件必须通过目录或后缀明确区分，禁止混用。

## 三、最终命名

公式：`[序号 ]学生姓名 文档类型关键词 选题名称.docx`

不得使用：test/final/output/V0.3生成版/AI测试/最新版/临时 等名称。

## 四、执行位置

命名检查在生成时执行（naming_check），不是交付后的人工整理。

## 五、Template Naming Parser

文件名必须由模板命名解析器生成：先解析模板文件名身份（序号/姓名/文档类型/选题），再替换动态字段。解析器：`00_系统配置/模块/v03/template_naming_parser.py`。
## 六、学生成果目录结构

每个学生生成成果时自动创建独立目录：

```text
06_输出成果/
 └── 专业方向/
      └── 学生姓名_毕业设计材料/
           ├── 01 学生姓名 毕业设计任务书 毕业设计题目.docx
           ├── 02 学生姓名 毕业设计成果 毕业设计题目.docx
           ├── 03 学生姓名 毕业设计成绩评定表 毕业设计题目.docx
           ├── 04 学生姓名 毕业设计答辩记录表 毕业设计题目.docx
           └── _过程记录/
```

## 七、编号规则

编号代表成果类型，禁止按生成顺序随机编号：

| 编号 | 文档类型 |
|---|---|
| 01 | 毕业设计任务书 |
| 02 | 毕业设计成果 |
| 03 | 毕业设计成绩评定表 |
| 04 | 毕业设计答辩记录表 |
| 05 | 毕业设计指导记录表 |
| 06 | 开题报告 |
| 07 | 中期检查表 |

## 八、Output Naming Sense

新增 Output Naming Sense 检查：

1. 文件名是否符合规范；
2. 学生姓名是否一致；
3. 毕业设计题目是否一致；
4. 编号是否正确；
5. 目录结构是否正确；
6. 不同学生是否隔离。

输出：output_validation_report.json。

详细规则见：`output_management_rules.md`。
