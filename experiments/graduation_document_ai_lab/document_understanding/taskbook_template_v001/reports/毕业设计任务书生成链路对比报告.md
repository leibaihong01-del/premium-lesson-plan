# 毕业设计任务书生成链路对比报告

日期：2026-08-05

## 结论

旧任务书生成能力与当前 Document Understanding 实验是两条独立链路。实验未调用旧生成器、经验与审核规则，因此只能做“字段填充”，不是“任务书生成”。

## 对比

| 项目 | 旧任务书生成 | 当前 Document Understanding 实验 |
|---|---|---|
| 模板来源 | 02_模板文件/01 杨振海 毕业设计任务书 黄金版 | 实验空间 source/原始任务书模板.docx（同源复制） |
| 生成入口 | v03/run_taskbook_case.py → taskbook_generator | schema_v0.1_auto.json → 简单字段填充脚本 |
| 字段规则 | 学生信息映射 + 任务书内容迁移（设计目标/任务/预期成果） | 按 label 单元格查找并填值 |
| 内容迁移 | 从学生任务书初稿按固定行列迁移 | 按行列位置迁移，无完整规则 |
| 格式保护 | 模板母版复制，不重建结构 | 模板复制，不重建结构 |
| 选题类型 | set_option_checked 处理勾选 | 仅填文本，未处理勾选 |
| 质量检查 | internal_audit：结构/内容/命名/页数/字号/虚拟表达 | 无质量检查 |
| 页数收敛 | 移除尾部空段落收敛到 2 页 | 未处理 |
| 经验调用 | taskbook TKM / Quality Memory | 未加载 |
| 黄金案例 | 杨振海黄金模板 + 王欢/邱志豪回归 | 未引用 |

## 为什么当前实验退化

1. Document Understanding 只看到“Word + 表格 + 文字”，不知道这是毕业设计任务书；
2. 未调用 taskbook_generator 的内容迁移与字段规则；
3. 未加载 taskbook TKM / Quality Memory；
4. 未执行 internal_audit；
5. 未处理选题类型勾选、空段落、页数收敛等已验证规则。

## 正确关系

```text
CourseAgent
  Graduation Design Skill
    ├── 原任务书生成能力（taskbook_generator + 黄金模板经验 + internal_audit）
    └── Document Understanding（模板理解 + schema 生成）

Document Understanding 不应替代原生成器，
而应给原生成器提供“模板理解能力”：

Document Understanding + 模板 Schema + taskbook_generator → 高质量任务书
```

## 下一步

1. Document Understanding 输出模板 Schema；
2. Schema 经人工校正后进入模板知识库；
3. taskbook_generator 以 Schema 为模板理解输入，继续使用原有内容迁移、格式保护与内部审核；
4. 保留旧生成链路作为生产主链，Document Understanding 只作为理解增强层。
