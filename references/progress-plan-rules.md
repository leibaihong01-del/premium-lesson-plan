# 教学进度计划生成规则

## 模板与页面

1. 页面：A4 纵向，页边距上 2.54、右 3.17、下 2.54、左 3.17 cm。
2. 标题：宋体 16pt 加粗居中；学期行同格式。
3. 信息字段：宋体 12pt，标签加粗、值正常；总学时与分配数字用下划线。
4. 表格：25 行 × 8 列，固定布局；`tblGrid` 949/743/688/2401/868/1693/707/473 twips；边框单线 auto sz4；单元格左右边距 108 twips；垂直居中。
5. 表格文字：宋体 10.5pt；行高 atLeast 自适应。

## 表头信息

1. 主讲教师、课程名称、选用教材、主编、出版社、总学时 48、课堂讲授 32、实训 16、其它 0、机动 0 均继承模板。
2. 授课班级补全专业全称（如“24级城市轨道交通通信信号技术1-6班”）。
3. 学期信息以模板或原计划一致为准（如“2025-2026学年春季学期”）。

## 表格内容

1. 第 1-16 行：项目 1-7 理论教学，共 32 学时。
2. 第 17-24 行：综合实训模块 1-7 + 过程综合性考核，共 16 学时。
3. 每个教学行“教学内容安排”追加一行“目标：…”（来自课标对应项目的教学目标/教学要求）。
4. 周次第 2-17 周连续，日期区间连续；教学形式多媒体/实操；课后作业保持模板。
5. 备注列窄，不填长文本。

## 审核

- 项目学时与课标表 1 一致（2、2、4、2、8、8、6、16）。
- 理论 32 + 实训 16 = 48。
- 周次与课程教案一一对应。
