# 课程内容映射流程

## 输入

- 课程标准优化版 .docx（表 1：项目、学时、教学目标、教学要求、思政）
- 教学进度计划优化版 .docx（周次、教学内容、学时）
- 原始教案 .docx（每课一份）

## 映射步骤

1. 逐份解析原教案：文件名、周次、教学项目、教学任务、主要内容。
2. 建立链条：课程标准 → 教学项目 → 教学任务 → 教学进度 → 对应教案。
3. 检查并标注问题：
   - 教案缺失（如综合实训无独立教案）
   - 项目遗漏
   - 教学内容重复（相邻课教学目标完全相同）
   - 任务与进度不一致（表头任务与正文内容不符）
4. 为每份教案制定优化策略：
   - A 类：保持结构，仅优化内容。
   - B 类：重新设计教学过程。
   - C 类：较大程度重构。

## 输出

- 16 份教案批量生成映射表 .xlsx，含工作表：教案映射表、课程体系对应关系、审核检查。

## 本项目实例（城市轨道交通列车运行控制）

- 第 1-16 课对应进度计划第 1-16 行，周次一一对应。
- 项目 1-7 全覆盖；综合实训 16 学时（第 12-17 周）需补充实训教案。
- 已处理问题：第 6-9、10-13、14-16 课目标重复；第 9、12、13、16 课表头与内容不符，按进度计划重构。
