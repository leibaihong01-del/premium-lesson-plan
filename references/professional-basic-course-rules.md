# 专业基础课程通用规则模板

适用于高职“专业基础认知课”类课程（如《城市轨道交通概论》），作为课程标准、教学计划、教案生成的通用约束模板。课程专属规则可覆盖本模板。

## 1. 课程定位约束

- 定位为专业基础认知课，服务新生建立行业与系统整体认知。
- 不设计过深专业维修技能；专项维护、故障处理、设备配置等内容交由后续专业课程。

## 2. 内容深度约束

- 主线：系统认知、岗位认知、设备认知、运行流程认知。
- 深度分级：基础介绍型（是什么、有什么、起什么作用）；深入铺垫型（结构、流程与相互关系，不展开设备级维修细节）。

## 3. 项目设计原则

- 项目框架与学时以课程编码和人才培养方案为准。
- 每个项目标注深度类型与衔接课程，形成“宏观认知→微观实操”递进。

## 4. 实训设计原则

- 突出系统认知与综合应用，采用参观认知、仿真演示、流程演练、岗位认知见习。
- 避免专业维护训练；实训目标用“认知与流程分析”表述。

## 5. 思政融合方向

- 五维方向：安全生产、工程责任、职业规范、交通强国、岗位使命。
- 按“项目 → 思政元素 → 案例”建立映射，案例结合行业发展与国产技术。

## 6. 后续课程衔接原则

- 明确哪些内容只做基础介绍、哪些内容需要深入铺垫。
- 课程链：基础认知课 → 专业系统认知 → 专业专项课程 → 岗位技能训练。
