# 精品课程教案生成规则库

## 一、页面规范

1. 页面：A4（21.0 × 29.7 cm），纵向，单节。
2. 页边距：上 2.54 cm、右 3.17 cm、下 2.54 cm、左 3.17 cm。
3. 页眉：保留模板图片（校徽等）；页脚：保留 PAGE 页码域。
4. 禁止手动分页与 pageBreakBefore；表格行高 atLeast 自适应。
5. 文档末尾空段落设精确 0 行距（`w:spacing line=0 lineRule=exact`，`sz=1`），防止空白尾页。

## 二、字体规范

| 角色 | 字体 | 字号 | 加粗 | 颜色 |
|---|---|---|---|---|
| 文件标题 | 宋体（继承默认） | 18pt | 加粗 | 默认黑 |
| 表格行标签 | 楷体 | 10.5pt | 加粗 | 1F1F1F |
| 表格正文 | 楷体 | 10.5pt | 不加粗 | 1F1F1F |
| 教学重点：/难点： | 楷体 | 10.5pt | 加粗 | 1F1F1F |
| 任务N标题 | 楷体 | 10.5pt | 加粗 | 7030A0 |
| 知识点N标题 | 楷体 | 10.5pt | 不加粗 | 7030A0 |
| 板书标题（标题：/一、二…） | 楷体 | 10.5pt | 加粗 | 1F1F1F |
| 教学设计正文中的课前/课中/课后 | 楷体 | 10.5pt | 加粗 | 7030A0 |

“教学反思”行标签为模板例外，不加粗。所有文字修改 run 级完成，禁止整段替换格式。

## 三、颜色规范

| 颜色 | 用途 |
|---|---|
| FF0000 红 | 思政融入行（标签加粗+正文不加粗）、思政金句 |
| 2E75B6 蓝 | 随堂练习/随堂互动/实操任务 |
| 70AD47 绿 | 预设答案/关键答案 |
| 7030A0 紫 | 任务N、知识点N、课前/课中/课后阶段标签 |
| 1F1F1F 深灰 | 正文、说明、板书标题 |

禁止：思政内容整体黑色、颜色错位、同一角色颜色漂移。

## 四、标题层级规范

1. 文档标题唯一，18pt 加粗居中。
2. 表内一级栏目（教学目标、教学重难点、教学方法、教学用具、教学设计、板书设计、“教学做一体”设计、教学过程等）加粗。
3. 二级表头（教学环节、主要教学内容（教师活动）、实施情况（学生活动）等）加粗。
4. 不使用 Word Heading 样式，全部使用表内段落格式。

## 五、表格规范

1. 固定 39 行 × 6 列；`tblGrid` 1261/1040/902/1454/1150/2715 twips；禁止增删行列、修改列宽与合并。
2. 合并结构：
   - R0/R1：标签/值/标签/值。
   - R2-R8：标签 + 内容（内容跨 5 列）。
   - R10-R13：标签（col0-1）+ 内容（col2-5）。
   - R17、R20-R27、R30-R32：教学环节/教师活动/学生活动三栏。
   - R35-R37：目标类型/达成情况/简要说明。
   - R38：反思内容跨列。
3. 边框单线 auto sz4；单元格左右边距 108 twips、上下 0；垂直居中。
4. 行高规则：R3、R8、R24 自适应（删除过大 atLeast）；R10-R13/R17/R31/R32=500；R30=400；R35-37=400/400/406。
5. 反思区 R38 固定 6 段：“针对本节课问题的改进方法：”+2 空行+“下节课需要调整的内容：”+2 空行。
6. 长句超过约 55 字拆为 2-3 段，段落级克隆、run 级改字。
7. 表格比对容错：空单元格、合并单元格、不同长度表格不报错，只比对结构与格式。

## 六、思政元素标识规范

1. 过程教学思政内容使用【思政融入】前缀，标签加粗红色、正文红色不加粗。
2. 思政金句红色加引号不加粗。
3. 教学目标中【思政育人目标】保持深灰正文，条目结合案例、工程、岗位表述。
4. 禁止单独罗列口号、重复表述、思政全黑。
5. 思政映射与课标表 1 对应项目一致。

## 七、教学设计规范

1. 90 分钟闭环：考勤 2min → 课程复习 3min → 新课预热 7min → 任务引入 5min → 传授新知 48min → 任务实施 20min → 任务总结 3min → 作业布置 2min。
2. 传授新知内部任务时间合计 48min，任务标题写清时长。
3. “教学做一体”设计：R10 任务与分时、R11 能力目标、R12 训练步骤与评价、R13 教学成果。
4. 教学过程教师活动与学生活动成对填写，体现任务导入、情境设计、学生参与、实践训练、过程评价、总结提升。
5. 教学设计 R7 开头写学情，正文含课前/课中/课后阶段词并加粗紫色。
6. 板书 R8：标题 + 一至五级结构，标题加粗，末行写岗位育人落点。
7. 作业分层：基础、提升、预习，配合学习通测评。
8. 内容一致性：章节对应进度计划行，目标/重难点/思政对应课标项目，学时一致。

## 八、分页规范

1. 中间页底部空白 ≤40pt，首页 ≤60pt（首页含标题区可放宽至 110pt）。
2. 不得出现空白尾页、行跨页后只剩空表格边框的碎片。
3. 超标时依次检查：删除 R3/R8/R24 过大最小行高、收紧 R10-R13/R17/R30/R31/R32 行高、精简超长句、反思区保持 6 段。
