# 批量生成映射表生成规则

## 输出

《16份教案批量生成映射表.xlsx》，3 个工作表。

## 工作表 1：教案映射表

列：序号、原教案文件、授课周次、对应教学项目、对应教学任务、课程标准章节（学时）、教学进度计划周次/行、原教案主要内容、优化策略类别、需增加任务驱动、需增加案例、需增加实践环节、需优化思政融入、备注。

优化策略类别：

- A 类：保持结构，仅优化内容。
- B 类：重新设计教学过程。
- C 类：较大程度重构（目标重复、表头与内容不符等）。

## 工作表 2：课程体系对应关系

列：课程标准项目、课标学时、教学任务、教学进度周次、对应教案、一致性检查。

覆盖项目 1-7 与综合实训；综合实训需标注教案缺失并建议补充实训教案。

## 工作表 3：审核检查

检查项：

1. 教案缺失（如综合实训无独立教案）。
2. 项目遗漏。
3. 教学内容重复（相邻课教学目标完全相同）。
4. 教学任务与进度不一致（表头任务与正文内容不符）。
5. 周次一致性（教案周次与进度计划行一一对应）。
6. 学时一致性（理论 32 + 实训 16 = 48）。

## 生成步骤

1. 逐课解析原教案：周次、章节、任务、教学目标摘要、教学设计。
2. 读取课标表 1 与进度计划表，建立对应关系。
3. 逐项检查并填写一致性结论。
4. 使用 openpyxl 输出 xlsx，表头加粗、列宽与换行设置。
