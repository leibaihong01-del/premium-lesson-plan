# 课程资料生成经验规则

## 持续优化与经验迭代机制

1. **问题发现**：每次任务主动检查内容、结构、格式与用户反馈问题。
2. **问题分析**：定位原因（模板解析不足/课程设计规则不足/文档优化规则不足），形成《问题分析记录》。
3. **解决策略**：提出临时修复与通用方案，判断一次性问题或系统性问题。
4. **规则沉淀**：重复问题自动生成规则，写入本文件与 `06_Skill规则库`。
5. **版本管理**：每次更新记录版本号、更新时间、问题来源、优化内容、影响范围。
6. **自我判断**：主动判断模板合理性、内容课程逻辑、规则冲突与优化需要。
7. **人工确认**：Skill 规则修改前生成《规则优化建议报告》，经人工确认后写入规则库。
8. **优化闭环**：执行 → 检查 → 发现问题 → 解决 → 总结 → 更新 Skill → 再次执行。

## 沉淀规则

1. 教学表格禁止出现孤立尾行，生成后必须进行分页优化。
2. 表格行高优先按内容自适应；短内容行设置合理最小行高。
3. 文档末尾空段落设 0 行距，防止空白尾页。
4. 批量转换采用单文件独立 Word 实例，每文件超时隔离并记录日志。
5. 课程标准等混排文档以墨迹覆盖率和页尾标题检查为准。
6. 扩展表格行数时克隆普通内容行，禁止复用合计行等合并结构行。
