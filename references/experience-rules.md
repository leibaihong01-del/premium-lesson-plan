# 课程资料生成经验规则

## 持续优化与经验迭代机制

1. **问题发现**：每次任务主动检查内容、结构、格式与用户反馈问题。
2. **问题分析**：定位原因（模板解析不足/课程设计规则不足/文档优化规则不足），形成《问题分析记录》。
3. **解决策略**：提出临时修复与通用方案，判断一次性问题或系统性问题。
4. **规则沉淀**：重复问题自动生成规则，写入本文件与 `06_Skill规则库`。
5. **版本管理**：每次更新记录版本号、更新时间、问题来源、优化内容、影响范围。
6. **自我判断**：主动判断模板合理性、内容课程逻辑、规则冲突与优化需要。
7. **人工确认**：Skill 规则修改前生成《规则优化建议报告》，经人工确认后写入规则库。
8. **优化闭环**：执行 → 检查 → 发现问题 → 解决 → 总结 → 更新 Skill → 再次执行。

## 沉淀规则

1. 教学表格禁止出现孤立尾行，生成后必须进行分页优化。
2. 表格行高优先按内容自适应；短内容行设置合理最小行高。
3. 文档末尾空段落设 0 行距，防止空白尾页。
4. 批量转换采用单文件独立 Word 实例，每文件超时隔离并记录日志。
5. 课程标准等混排文档以墨迹覆盖率和页尾标题检查为准。
6. 扩展表格行数时克隆普通内容行，禁止复用合计行等合并结构行。

记录格式：

【经验编号】E-XXX

问题：

产生原因：

解决方案：

适用场景：

影响范围：

版本号：

【E-001】
问题：教学表格跨页产生大块空白。
产生原因：内容行设置过大最小行高，Word 无法自然跨页。
解决方案：大内容行内容自适应，短内容行合理最小行高，尾部空段落 0 行距。
适用场景：教案、实训教案等整表文档。
影响范围：分页质量。
版本号：v1.1。

【E-002】
问题：分页脚本误判末页自然留白。
产生原因：末页与中间页使用同一空白阈值。
解决方案：末页只检查空白尾页。
适用场景：PDF 分页检查。
影响范围：分页检查脚本。
版本号：v1.2。

【E-003】
问题：混排文档被误判为“大面积空白”。
产生原因：仅按表格底部空白判断。
解决方案：以墨迹覆盖率和页尾标题检查为准。
适用场景：课程标准、教学计划。
影响范围：排版审核方法。
版本号：v1.3。

【E-004】
问题：扩展表格时误用合计行当内容行，合并单元格错位。
产生原因：未区分普通内容行与合计行结构。
解决方案：克隆普通内容行扩展，合计行保留末尾。
适用场景：课程标准表1、教学计划表。
影响范围：表格结构正确性。
版本号：v1.4。

【E-005】
问题：教学计划模板行数多于课程所需。
产生原因：模板学时与课程学时不一致。
解决方案：按课程学时删除多余内容行，保留列宽、字体与合并结构。
适用场景：教学进度计划生成。
影响范围：表格行数与分页。
版本号：v1.7。

【E-006】
问题：表头信息整段替换破坏加粗与下划线格式。
产生原因：未按 run 级处理。
解决方案：表头按 run 级逐段替换。
适用场景：教学进度计划、课程标准表头。
影响范围：模板格式继承。
版本号：v1.7。

【E-007】
问题：课程标准基础信息未按权威文件核验。
产生原因：缺少生成前校验与反向验证。
解决方案：建立课程建设智能诊断层；冲突时停止生成并请求人工确认。
适用场景：课程标准、教学计划、教案生成。
影响范围：课程基础信息准确性。
版本号：v1.8。
