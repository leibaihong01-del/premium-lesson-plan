# 精品课程文档排版优化规则

适用范围：课程标准、教学进度计划、教案、实训教案等所有课程文档。

## 总体原则

达到正式教学文件排版标准：内容完整、页面紧凑、表格美观、阅读流畅；避免大面积空白、机械分页；保持模板风格。

## 表格优化

- 模板表格结构优先，禁止为排版增删行列。
- 按内容长度调整行高、单元格高度、段落间距与内边距。
- 禁止：跨页大量空白、标题孤立页底、表格最后只剩一两行。
- 短内容紧凑，长内容拆分段落；禁止无意义填充。

## 页面连续性

- 检查异常空白、半页空白、单独标题页、表格断裂、章节孤立。
- 优化顺序：段落间距 → 表格行高 → 分页位置 → 页面调整。
- 禁止为排版删除有效内容。

## 文字排版

- 统一字体；首行缩进、行距、段前段后符合模板。
- 标题层级：一、二、三级。
- 避免标题后只有一行内容被分页。

## 视觉检查

Word 生成 → PDF 转换 → 逐页检查（表格变形、大面积空白、跨页异常、字体协调、视觉规范）。

混排文档（如课程标准）以墨迹覆盖率和页尾标题检查为准，不以表格底部空白为准。
