# 全过程一致性追踪机制 V1.0

## 核心思想

目标定义 → 依据分析 → 方案设计 → 生成过程 → 过程校验 → 结果审核 → 经验沉淀，每一步保留输入依据、分析过程、决策理由与输出结果。

## 机制

1. 项目开始时生成《项目目标基线表》。
2. 每阶段生成前后执行目标对齐检查。
3. 过程偏移检测：资料与初始目标冲突时判断保留/删除/调整定位，禁止全盘吸收。
4. 决策日志：`07_项目知识库/decision-log/项目决策记录.md`。
5. 证据链：任何输出可追溯“为什么这样做”。

## 核心原则

全过程一致性：所有任务保持“目标—依据—过程—结果”一致；发现偏离时暂停自动执行、分析原因、提出调整建议、等待用户确认。
